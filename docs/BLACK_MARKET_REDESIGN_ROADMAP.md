## 關鍵產品規則與不足處理
1. **現有 `ITEMS` 無 item-level、rarity 欄**：因此第一批只建立*明確標注為展示級別*的 UI 資料，灰5/綠15/藍30/紫50，只為商品目錄視覺；不替換 RPG 等級或修改裝備傷害。卡牌在黑市交易的是 Lv.1 複本，即使玩家持有 Lv.IV 主卡，也不將黑市供應複本誤標 Lv.IV。實際交易價格依 `marketVendors.ts` / `CARD_PRICES` / `marketSellPrice` 決定，與展示級別無關。
2. **四階目前商品分布不一定全部有現貨**：第4階「禁忌」對應真正 chaos 稀有卡，現有五商人可能暫未供應；僅提供視覺階級與未來資料擴充能力，禁止憑空出售假商品。
3. **買入卡牌 supply 目前用 99 作為無限的 legacy 內部 sentinel**：商品列表及詳情顯示「不限」而不是偽造有99張庫存；出售模式顯示玩家真實複本數，實體商品顯示目前已售出後的實際庫存。顯示零庫存但保留不能交易原因。
4. **世界時間是事件推進，不是按秒實際流動**：輪班倒數應依下個遊戲時段算剩餘「世界時間」；玩家未進行時間消耗行動時，數值不會自行逐秒減少，否則會與實際商人輪班、價格驗證矛盾。只有台詞每10秒按真實秒數換句。
5. **插圖2為固定黑市場景參照**，目前遊戲已存在五名不同身份輪班商人。新背景不可抹掉動態商人姓名、職業、交易清單與 `vendorId`；同一張圖是場所/氛圍背景，不代表改成單一 NPC。不得依圖1範例商品憑空引入遊戲不存在的物品。
6. **壓縮資產交付**：原JPEG 695,892B；960×536 WebP q52 約32,380B（-95.35%，已於開工前本地測試）；第2批再正式進GitHub並在 UI 引用，避免首批市場資料改版和場景改版同時出現過多回歸。

## v0.8.24 第三批補充定案（2026-11-13）
- 販賣的**可見物品以背包 s.bag 為唯一實體來源**；只存倉庫的物品完全不屬背包陳列。所有實體物品若商人不收購/受保護/穿戴中，可點開詳情但確認出售 disabled、提供原因。
- `MARKET_SELL_ITEM` 實際扣除也必須僅使用 `s.bag`；以前 warehouse-first 的行為在本批修正。原商人收購 whitelist 與其他交易守衛照舊，這是必要的一致性修正。
- 卡牌複本在 `ownedCards` 獨立存放，販賣頁的卡牌分類僅陳列玩家複本 >0 的卡，不得把原卡主體誤當可賣複本；不收購時仍顯示但禁賣。
- 左側單一整區 toggle，原圖3向量重繪並染銅金色；箭頭只能在圖示自己中心轉180°，文字上下交換、啟用放大/停用灰淡；有鍵盤/觸控/降低動效。
- 後續第4~6批仍不自動啟動；v0.8.25 才處理十秒自言自語，v0.8.26 才處理交班世界時間倒數。
