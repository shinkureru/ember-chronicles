# 餘燼紀事｜遊戲設計規格 v0.6

> 2026-11-07｜狀態：核心方向已討論，第一個可玩原型實作中。
> 「已確認」指先按目前決策開發，非代表不可以日後再平衡；「原型提案」數字不等於已正式定案。

## 1. 遊戲定位

- 類型：劇情推進的長篇 Roguelite 卡牌 RPG。
- 平台：手機 Web + 電腦 Web 同一套直式遊戲畫面；後續以 Capacitor 封裝 App。
- 所有選項以主角第一人稱想法撰寫，NPC 對話保留角色原話；環境描寫以主角感受呈現。
- 玩家先進入關卡，經歷環境、人物對話、生存、探索、搜刮、衝突等多種類型事件。
- 玩家可失敗但不重置世界或失去已取得物品；世界依玩家行動持續變動。

## 2. 六種職業（完整遊戲）

| 職業 | 四項主動技能 | 被動天賦 |
|---|---|---|
| 調查記者 | 追問破綻、交叉查證、暗中蒐證、輿論施壓 | 情報嗅覺 |
| 急救護理師 | 生命評估、緊急處置、情緒安撫、檢傷決策 | 生命徵兆 |
| 維修技師 | 結構解析、臨時改裝、裝置干擾、緊急修復 | 機械直覺 |
| 律師 | 程序質疑、條件交換、舉證反制、協議締結 | 權責洞察 |
| 舞台演員 | 即興扮演、情緒鏡像、虛張聲勢、轉移焦點 | 讀場天賦 |
| 外送騎士 | 路線預判、爆發衝刺、穿梭地形、緊急投遞 | 街區記憶 |

職業具有不同資源的累積、消耗、恢復速度與技能強度。目前原型只實作「調查記者、外送騎士」；其餘仍為企劃規格。

## 3. 情境行動卡＋技能卡

- 情境行動卡由目前場景、NPC 狀態、持有物及歷史記憶篩選產生，通常提供 3 個可選行動。
- 職業技能及通用技巧從目前牌組抽取，可附加到符合條件的情境行動卡。
- 附加前後「每個選項」必須顯示**最新成功率**、確定消耗與影響；臨界門檻警告要附帶負面效果、可恢復方法。
- 可能後果可概述，未來 NPC 的秘密反應不必全部揭露。內部結算與畫面預覽必須使用同一套判定規則。
- 失敗、成功均可能改變 NPC 對玩家的認知及後續事件。
- 專屬職業資源不足時，仍保留合理的基本情境行動。

## 4. 卡牌收藏與升級

- 卡牌持續保存，不隨章節重新開始；章節透過法律、氣候、文化及環境影響適用性。
- 主動牌組有容量上限。第一個原型暫以 20 張容量目標，初始牌組 10 張。
- 重複通關可在 NPC、桌面抽屜、環境等來源搜得重複卡牌及物資。
- 最高 V 等。每次升級的**重複卡**需求：

| 進階 | 普通 | 稀有（半數，無條件進位） | 混沌 |
|---|---:|---:|---:|
| I→II | 5 | 3 | 1 |
| II→III | 8 | 4 | 1 |
| III→IV | 10 | 5 | 1 |
| IV→V | 12 | 6 | 1 |

- 黑市價格偏高；玩家可以拿多餘卡出售提高商人好感，解鎖稀有隱藏卡；買卡適合最後差一兩張時補足，不應是主升級途徑。
- 多餘實體卡可作野外燃料，也可能被短期商人、店家、路人 NPC 收購，換食物、保暖衣物、便利工具等不過度影響平衡的獎勵。
- 職業技能或被動可影響與該職業相關的特殊升級與進化機會。

## 5. 生命、生存與永久成長

- 即時狀態包含生命、體力、膽量、飢餓、疲勞、體溫與職業資源。
- 傷勢、疾病、食物腐敗等可以連鎖影響多項即時狀態，效果應符合合理生理反應。
- 永久屬性 18 項：生命上限、體力上限、移動能力、近身戰技、身體耐力、環境適應、觀察力、推理能力、記憶能力、專注能力、臨機應變、規劃能力、說服能力、欺瞞能力、談判能力、同理能力、威嚇能力、心理韌性。
- 永久屬性緩慢成長；一般支線永久獎勵集中在**單一主要屬性**，不在做一次任務後同時提升 5–6 項。
- 不採用提升某永久屬性就強迫降低另一永久屬性的機制；機會成本來自時間、選擇及資源。

## 6. NPC 記憶與重訪

- NPC 擁有當前情緒、對玩家的信念、長期記憶、個人目標、對特定手法的防範。
- NPC 只知道他有能力知道的事情；不會全知玩家暗中的決定。
- 再次遭遇時主角和 NPC 的台詞應明顯反映「這已經第幾次」以及之前發生的特定事件。
- NPC 適應只針對曾見識的手法；玩家透過真實取得的情報，長期優勢應比 NPC 的抗性成長更大。
- 原型成功率測試架構：`P = clamp(50 + 1.2 × (S − R) + I − A + C, 5, 95)`；原型目前依不同事件的 `baseChance` 與加成計算，屬**簡化實作**，以便驗證展示與實際判定一致。
- 玩家每次戰敗保證得到有用新線索，下次攻略具有實際加成，不因反覆失敗無限制疊加；線索可以解鎖選項或改善判定。

## 7. 撤退與失敗

- 主動撤退需依體力、移動能力、負重、傷勢、追兵、環境及道具等計算成功率。
- 每次撤退都要顯示**無法永久跳過**的懲罰確認；代價偏輕、可恢復，不得讓玩家無法再次挑戰。
- 太早撤退可失去本來有機會搜刮的物資；資訊收益比戰敗弱，不能透過連續撤退無限刷成功率。
- **失敗後不會遺失、被扣留或被 NPC 沒收已獲得物品**。

## 8. 世界時間與搜刮

- 世界時間為「早上、中午、下午、晚上、深夜」五階段；不同時段 NPC 出現及活動可以不同。
- 選項和搜刮推進世界時間；玩家停留在畫面上思考不會自動推進時間。
- 勝利後可選擇搜查 NPC 口袋、身上穿著與手拿裝備、抽屜、環境；不保證每次出同一種戰利品。
- NPC 身上物品要符合職業、場景、條件，至少規劃 100 種日後可擴充的物品。
- 已拿走的 NPC 物品不會沒來由重新出現，除非世界邏輯有補給來源。

## 9. 負重、背包與倉庫

- 輕量負重機制；過重影響移動、撤退等判定。
- 新手教學就取得容量有限的倉庫；返回據點後將非指定物品自動轉入倉庫。
- 常用裝備可標記永久保留在身上；仍可自行解除標記。
- 滿倉時提醒玩家，未入倉物品仍保留，不能無預警丟失。玩家進新關卡前知悉攜帶風險。

## 10. 跨職業學習

- 透過六名職業代表的共同朋友間接學習其他職業能力，效果約原版 50%。
- 六名代表人物平時不易直接接觸，可能作彩蛋少量露面。
- 長篇專屬劇情後，可向**最多兩位**職業代表直接學習，效果最高 90%。
- 學習前要多次清楚提醒剩餘兩個稀有名額；若選錯可透過「遺忘技能」任務付出重大代價重置，且對應角色好感度大幅降低。
- 永久解鎖不等於可以無限制同時裝備所有跨職業卡牌；完整裝備上限尚待平衡。

## 11. 視覺與實作方向

- 同一套手機直式 UI，桌面版置中，寬度約 430–468px；手機高度自適應，文字可自然捲動。
- 簡潔有力的選牌、附加技能、數值更新、傷害命中動畫；目標手機穩定 60 FPS，尊重降低動態偏好。
- React + Vite + TypeScript + React Router；將資料、規則、場景、UI 分層。
- 原型先做 1 關、2 職業、少量技能與物品、存檔及調試。其餘功能在 `PROTOTYPE_SCOPE.md` 持續追蹤。


## v0.3 公開測試與視聽介面規則

- Web 公開測試先選 GitHub Pages；手機直式與電腦中央直式共用 UI，之後可用 Capacitor 封裝 App。
- 核心視覺是黑暗恐怖，避免可愛與明亮風格；字型為 Noto Sans TC、Inter、Noto Serif TC。
- 背景恐怖配樂、環境音、操作及事件音依場景分離，允許玩家在設定頁調整總音量與各音量通道。
- 進入任務後關閉非任務選單及路由；採固定視窗高度，選項分頁、劇情全文和技能改在覆蓋層查看。
- 取得道具/技能卡/獎勵與重大事件需醒目彈跳提示，嚴重事件附震動回饋。
- 現階段沒有雲端存檔；GitHub Pages 並不能自行解決跨裝置存檔問題。


## v0.4 介面設計補充

牌組每頁 3×4 共 12 格；卡牌詳細資訊採浮動面板呈現，含取得方式、故事、目前持有本體＋素材複本。人物裝備互動不應造成版面位移。地圖所有系統入口集中。任務主畫面優先擴大場景與故事，行動卡區占比不超過約 36%，並保留固定的按鈕高度。選中行動卡時，若可附加有效技能卡則顯示慢速柔和脈衝提示。任務期間允許使用設定視窗調整音量與手動存檔，但仍鎖定地圖、倉庫及其他主選單。倉庫以暗色條列每頁 15 筆。場景心聲以第一人稱手動輪播，同一情境可有大量不影響邏輯結果的氛圍文字。
