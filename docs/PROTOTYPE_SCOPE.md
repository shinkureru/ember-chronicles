## 建議接下來的工作順序

1. 在本機實際跑起來並用 Chrome 手機模擬測試操作完整流程。
2. 把「一次關卡」改成更多個連貫事件：人物、環境、補給與衝突，先擴充到 8–12 個有差異的節點。
3. 強化任務事件規則結構，支持 NPC 日夜出沒與角色職業條件式選項。
4. 補卡牌收藏、可裝備牌組與黑市交易，連接真實升級效果。
5. 撰寫六職業差異、統一文字風格與 UI 動畫。

## 驗證檢查項目

- 技能卡附加前後顯示數字與實際扣除相符。
- 角色數值越過臨界門檻時，事前警告有實際內容。
- 撤退不能跳過代價確認；失敗線索保證有下一次加成。
- 退出、重新整理後可繼續原本進度。
- NPC 第二次重逢，有反映先前行動的文字，而不是只更新數字。
- NPC 的手電筒、對講機、防護背心一旦取走，就不會在沒有理由時再次產生。
- 滿倉後物品不得悄悄消失；被指定保留的裝備不自動入倉。
- 手機 viewport 360px、390px、430px 與桌面 1920px 的畫面都正常。
