## 設計邊界
1. **開場畫面**：每次完整重新開啟或重新整理都播放簡易滿版封面，簡單過場即可，最終視覺由使用者未來重新設計；不得出現手機版 468px 遊戲框架蓋住全屏。
2. **故事序章**：首次新存檔 = 世界觀圖文暫存 + 可略過介紹；接著必須先進入「新手教學／必敗關卡占位」，**跳過只跳過故事文字**，不能直接跳過教學必敗；結束後三基地選擇，設置進度為已完成，不會每次新開啟都重選。這次仍以占位為主。
3. **三基地主畫面**：完成選擇後首頁為本人基地，不顯示舊章節路線圖。必須保留原章節存檔與章節頁/戰鬥引擎供日後測試；要不要讓地圖桌/工作台解鎖路線圖**未決**，不可搶先綁死；建議另有開發 QA 存取點。
4. **家具提示**：輪廓柔和呼吸、任務重要提示可有小光點，避免高速頻閃；未來使用單一觸發規則（教學/未讀支線/建造可領取），只為已購入家具顯示，動畫依 `prefers-reduced-motion`。
5. **HUD**：未決，**不能擅自重設**；請維持原生命、體力、台北時鐘、飢餓及遊戲操作可見，後續與使用者討論。
6. **三避難所差異**：暫以背景/容量敘述呈現，不預先強加數值影響；待使用者定案再設計防禦、生活成本、倉儲加成。
7. **測試按鈕**：明確標 `prototype only`，正式版刪除；避免永久公開進入方式破壞玩家進度，尤其自動隨機、全配與清空。
8. GitHub CI `npm run build`、`npm test` 需每批全綠；自動測試不等同手機真實視覺驗收。
