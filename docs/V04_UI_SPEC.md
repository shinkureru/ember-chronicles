# Prototype v0.4 — UI 改善與驗收清單

## 設計共識
- 黑色／暗灰／暗紅恐怖風格，所有頁面使用相同的直式遊戲外框。
- **牌組**：每頁 3×4（12 格），不足 12 張時保留空格；未擁有卡也有鎖定狀態。每張點擊後開啟詳細視窗，顯示能力、故事、目前已實裝或尚待實裝的取得來源、目前等級、總持有量（本體 + 可用複本）、升級需求。
- **人物**：全身裝備六部位；切換部位時，卸裝按鈕的空間固定保留，沒有裝備時顯示不可使用的同尺寸按鈕。原場景的固定像素定位改成相對位置。
- **音效**：提升操作效果輸出音量，使用 dynamics compressor 緩和同時播放多音源時的過大音量；沿用總音量／音樂／環境音／操作音四軌調整。
- **地圖**：城鎮、黑市、倉庫、人物、牌組、設定集中在地圖頂部六格樞紐；地圖不重複呈現底部主選單，以保留更多關卡視覺空間。十二關依然位於可左右拖曳的地圖，按進度解鎖。
- **關卡**：場景插畫佔比提高；劇情、NPC 對話與場景內心話共用固定故事區。手寫 120 段依情境挑選的第一人稱內心話，使用手動輪播避免自動跳字打斷閱讀。
- **行動卡**：固定三張，區域上限約 36% 高度，避免互動後新增長內容擠動頁面；完整行動說明可在「全文」閱讀。
- **附加技能提示**：選取行動後，如目前手牌至少有一張相容且資源足夠的技能，附加技能按鈕柔和脈衝；沒有可用技能、或已附加技能，便不脈衝。
- **關卡設定**：右上角有設定按鈕，可調整四軌音量與立即存檔；設定是模態視窗，不解鎖地圖及其他遊戲頁面。
- **倉庫**：條列式，每頁 15 筆，保留重量、數量、保護及取用操作；極短螢幕只讓物品列表內部捲動，整頁仍固定。

## 驗收流程（Windows Chrome + Android/iPhone 實機）
1. 牌組：確認每頁 3 欄×4 列；點擊已擁有、未擁有卡並核對故事／來源與持有數。
2. 人物：反覆切換有／無裝備的部位，確認全身輪廓與裝備資訊不跳位；測試 320px 寬螢幕。
3. 地圖：進畫面立即可見六個功能入口、地圖與選中關卡資訊；左右滑動不會讓整頁垂直捲動。
4. 關卡：在 360×640、390×844、430×932、桌面 1080p 的直式外框測試。優先確認場景大於舊版、行動卡不超過約 36% 面積。
5. 關卡：選擇有技能可用的行動，附加按鈕脈衝；選擇無相容技能／資源不足情境時不脈衝。
6. 進關卡右上角設定：四軌音量可變動、立即存檔；關閉後仍停留在原關卡與選項。
7. 倉庫：製造超過十五種類的測試物品，確認分頁顯示每頁十五筆，不會被裁掉。
8. 音效：以耳機與手機喇叭分別測試按鍵、取得道具及打擊音，確認沒有破音或令人不適的音量峰值。

## 本機存檔與遷移
維持 `ember-chronicles-prototype-v1` localStorage key。v0.4 未清除或遷移 v0.3 的進度資料；重複卡的 `copies` 是額外素材數，玩家擁有總數 = 一張本體 + 素材數。
