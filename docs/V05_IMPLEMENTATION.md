# Prototype v0.5 — 純黑 UI、漂浮卡牌與技能比較

## 已實作

- **關閉按鈕置中**：卡牌詳情、附加技能及共用彈窗的 X 使用固定 32px 正方形 Flex 置中，避免字體行高導致錯位。
- **第一人稱心聲自動輪播**：關卡使用每 5.5 秒切換與 CSS 漸入漸出，移除上一段／下一段按鈕；在設定、技能、全文或撤退面板開啟時暫停。
- **灰階主題**：純黑頁面、灰黑面板、灰白文字。原有場景畫面保留場景色彩；重要正向數值亮綠，負向數值鮮紅。
- **漂浮式橫向主動卡**：保留卡牌名稱、主角心聲、成功率、體力、膽量、時間；超過螢幕寬度可左右滑動，尊重系統降低動態效果設定。
- **附加技能即時比較**：在原始主動卡下方透過箭頭顯示附加後卡牌，對比成功率、體力消耗、膽量、時間、職業資源。使用 `getSkillComparison()` 呼叫與實際 `CHOOSE` 相同的 `calculateActionPreview()`。
- **資源即時顯示**：當前／附加後資源及資源上限。計算允許未來引入資源恢復卡（負資源消耗）。
- **音效重製**：依操作、卡牌、搜刮、肉搏、受傷、喘息、腳步、警示分別產生不同聲音；音效與背景音量提高並以混音壓縮器控制峰值。
- **原創旋律 BGM**：各聲音場景定義獨立八步音符序列與節奏（短旋律 + 低強度環境層），並非使用任何第三方音檔。播放仍遵守瀏覽器需使用者互動才能啟動音訊的規則。

## 本版不包含

- 攻擊牌組事前準備、武器對應、自動領取武器及敵人 HP；這些已排定 v0.6。
- 正式錄製的環境擬音或完整商用恐怖 BGM；目前採原創程式合成的原型音樂與音效。

## QA

- 驗證 320px 與 390px 寬度、568px 至 932px 高度：關卡不應需要捲動整頁。
- 確認主動卡可左右拖曳，選中不會重排卡牌。
- 確認附加「路線預判」時成功率、體力與剩餘資源顯示一致。
- 確認滑桿音量最小與最大值，不應造成耳機刺耳峰值。
- 確認場景變化會切換旋律；靜音與 `prefers-reduced-motion` 正常運作。
