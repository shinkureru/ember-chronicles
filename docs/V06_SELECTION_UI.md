# Prototype v0.6 — 關卡選牌視覺重構

本版本調整「關卡中行動選擇」的**呈現流程**，原有 CHOOSE 規則、存檔及成功率公式不變。

## 前置修補
- v0.5.1 (PR #3) 修正關卡上方「全文／設定」按鈕超出畫面；標題列提高至 38px 並支援 safe area。
- v0.6 分支直接從 v0.5.1 修補分支建立；合併順序先 #3 再 v0.6。

## 選牌階段（ActionDecision）
- 關卡先展示「漂浮文字選項」而非有框線卡片。使用 Google Fonts **Noto Sans TC 900** 粗字、傾斜／微幅浮動。
- 使用 `choiceLayout.ts` 以預先分配的安全座標取代完全亂數，避免一般 3～4 選項互相重疊。分配由關卡、場景、嘗試次數決定；同一場景 re-render 不會跳位。
- 根據玩家可見成功率、消耗與狀態警告，挑出相對危險的一項做低頻灰階雜訊提示。這只是風險提示，**不揭露 NPC 隱藏後果**。
- 選項按鈕仍保有 aria-label，包括成功率及第一人稱想法，支援鍵盤及輔助科技。

## 確認階段
- 點選選項後以短暫淡入動畫進入左側破邊卡牌＋右側無框文字操作畫面。
- 左側 SVG 手繪崎嶇邊緣保留卡名、第一人稱想法、基本詳情、正確成功率／消耗；卡下方是附加技能入口。
- 右側「回到選擇...」「確定使用」均為真正可按的按鈕，點擊時縮放回饋。
- 右下角 SVG 心電圖脈衝傾斜播放；尊重 `prefers-reduced-motion`。

## 技能階段
- 「附加技能卡」開啟同頁全螢幕深色介面，上方沿用原本正確的 `getSkillComparison` 前後數值／職業剩餘資源。
- 下方的技能卡各自旋轉、上下錯開、緩慢浮動，橫向可滑動；多張時顯示滑動提示並讓下一張露出一部分。
- 每次重開技能介面，位置偏移會改變；技能可用性、資源與原本規則相同。
- 保留底部固定確認按鈕，關閉後回到相同主動卡的確認階段。

## 手機驗收
- 320×568、360×640、390×844、430×932、桌面 1080p 直式框
- 標題右上按鈕不裁切、沒有整頁垂直捲動。
- 3～4 個文字選項不重疊；加入更多選項前要加分頁（目前安全區以 1～6 選項設計）。
- 選牌 → 返回 → 再選 → 技能 → 返回 → 執行，原本數值結果與實際結算一致。
- 有較多技能時可以水平滑動，最下方「確認附加」始終可點。
- 降低動態效果的系統設定會停止漂浮、雜訊、心電圖及進場動畫。
