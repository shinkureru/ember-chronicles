# Prototype v0.7 — 攻擊型主動牌、敵人生命與事前準備

本版本建立戰鬥牌組資料、實際敵人 HP、武器持有檢查與限 5 張的事前準備。沿用 v0.6 第一人稱劇情及散落選牌界面，不重置 v0.6 之前的玩家進度。

## 使用流程

1. 地圖的「事前準備」入口或第一關進入按鈕，開啟 `/preparation`。
2. 上方是最多五張已選攻擊牌（空格保留）；下方是目前已擁有的攻擊牌。選中後可再次點擊移除。
3. 有對應武器在背包或倉庫的攻擊牌顯示較亮；缺少物品的卡片變暗、但仍允許選入牌組。
4. 當玩家選入攻擊牌、倉庫有相應武器、背包未持有且重量未滿時，武器**立即移到背包**，以第一人稱文字提示。
5. 未選攻擊牌、或帶有目前缺武器的攻擊牌時，進關前會顯示不能跳過的確認視窗。玩家仍可選擇不帶武器進關，以交涉、潛行等其他方式通關。
6. 若攻擊牌組已準備妥當，進入任務；此時任何主選單／倉庫都不可開啟。
7. 到「最後對峙」場景，新增攻擊型選項；如果超過六項，沿用 v0.6 的散落字體、分頁顯示。
8. 若背包沒有該攻擊卡所需物品，選項變暗且不可執行；搜刮或事件取得物品後立即可用。
9. 命中時按卡牌傷害與永久屬性／升級修正敵人 HP，敵人 HP 歸零時進入勝利搜刮場景；失手則會受到反擊，生命下降。原有的非戰鬥行動仍可通關。

## 初版數值與規則

- 第一章管理員敵人：HP **28／28**（每次重新進入關卡重設）。
- 攻擊牌的基礎傷害與成功率由 `src/game/data/attacks.ts` 定義，傷害升級每階 +2，能力修正受上限 99 約束。
- 攻擊卡是獨立行動類型，**不加入原有的附加技能抽牌池**，僅在對峙等適用場景顯示。
- 首批攻擊卡涵蓋鋼筆、記事本、相機、金屬直尺、手電筒、扳手、起子、對講機與水瓶等；物品必須實際在背包裡才可使用卡牌。
- 原有負重上限 15kg，倉庫 30kg；重新開始關卡時會儘量從倉庫重新備妥選中的攻擊牌武器。
- 攻擊牌所需工具在玩家選擇的牌組中仍有效時，離開關卡後視作已準備的隨身工具，不會被自動收入倉庫。
- 原有 3×4 牌組圖鑑新增「功能／附加技能」與「攻擊型主動牌」分類，攻擊卡有詳情、持有數、升級與物品需求。
- 以 `src/game/state/storage.ts` 對 v0.6 舊存檔做一次性補值；保留 NPC 遭遇、章節、金幣與現有物品。
