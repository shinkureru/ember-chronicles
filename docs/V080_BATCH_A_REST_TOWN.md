# v0.8.0 Batch A｜休息動畫、真實恢復預覽、城鎮狀態儀表

狀態：分支 `feature/v0.8.0-rest-and-town-status`，基準 `main:4ef2eccc77bec18d4ec2c0a476a798a9cb56716e`，尚未合併與部署。

## 已實作
- 三種床位確認休息後，各有不同的房間光線/角色姿勢/呼吸動畫：普通床位、安靜單人房、短暫打盹。動畫約 4.85 秒，可手動跳過。休息**立即依 reducer 真實結算一次**，動畫只負責呈現，不會重新扣錢或重複結算。
- 音樂：使用目前遊戲 WebAudio 播放**全新原創**短旋律，三種休息有不同五聲音型；尊重音樂音量、靜音、瀏覽器自動播放限制。不是外部錄音/未授權音樂，無新增音樂授權需求；跳過時停用旋律並回復原場景音量。
- 血量/體力預覽：現值以較飽和的紅/綠條、回復區以同色系淺色延伸表示；變更方案時維持寬度/起點平滑動畫。底下增加量永遠由 `after - before` 算出，與真實引擎 `previewInnRest` 一致，避免畫面顯示 +1 但數字跳 +8。已可回滿時不再提示繼續刻意降體力。
- 城鎮「生命 HP / 體力 ST / 飢餓 / 疲勞」四條真實進度條，飢餓和疲勞偏高表示危險。外傷/感染/中毒/疾病各有圖示、層數及可展開文字，不讓長敘述擠壓上方狀態。
- **現有負面狀態效果須保持誠實**：外傷累積與繃帶/清創已實作；感染/中毒/疾病的治療已實作，但尚未建立額外持續扣血／最大生命值減少等引擎公式。因此 UI 明示目前有效規則，沒有宣稱這些尚未實作的懲罰已經生效。後續可獨立設計並測試。
- 版本號由 `v1.7.5` 改為 `v0.8.0`（尚未正式 1.0），`package.json` 與 lock 同步。**不變更 localStorage key、GameState 版本、不清除玩家存檔**。
