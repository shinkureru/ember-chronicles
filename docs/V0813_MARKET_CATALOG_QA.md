# v0.8.13｜黑市商品陳列可視區放大與商品卡縮小

## GitHub 基準 / 修改邊界

- 2026-11-13 起始 `main` `94e2c6f00ba7673a618c75c9f41adb03eddd52d7`，前一批 PR #38／v0.8.12 已合併且 Pages 部署成功，開工時 open PR = 0。
- 唯一分支 `ui/v0.8.13-market-expanded-catalog`，**本批只有黑市商品展示密度與排版的 CSS**。
- 對應使用者圖片 4 黃框：將商品展示從畫面中段延伸到購買／出售按鈕上方，人物與對話保留，但不要佔掉大半垂直空間。

## 具體規格

1. `market-v12__meeting` 由舊 53% 縮到 `clamp(162px,29%,295px)`（不足 700px 高時 `clamp(145px,28%,200px)`；極矮 520px 內 135px）。`market-v12__table` 改 `flex:1 1 0`，吃滿剩餘高度。舞台的原有牆壁、人物剪影、商人名、時間、對話、好感度不刪除。
2. 原人物場景縮短後，將對話固定於好感度上方，避免兩者碰撞；對話過長時只有對話自己的最大高度限制。保留好感數值及時間。
3. 商品卡三欄排列，窄於 376px 切兩欄。高度由舊的 106～135px 縮至 88～100px，窄螢幕 93～106px，短高進一步降至 82～88px；商品卡仍有較完整的點擊區。
4. 商品卡內部依固定順序呈現 **ITEM/CARD → 圖示 → 名稱最多兩行 → 價格**。名稱使用兩行保留區和 `overflow-wrap:anywhere`，價格使用等寬數字字形避免每張卡上下跳動。圖示上限 35px，卡片左右至少 5～6px 留白。特別長的名稱在商品詳情中可完整閱讀，卡片保留全名 `aria-label`。
5. `market-v13__filter-wrap`、購買／出售、底部版本/設定及返回主畫面維持可見並照原本流程操作。**僅商品 Grid 垂直捲動**，繼承 v0.8.10 的共用拖曳 Hook；滾輪、觸控、鍵盤可操作。底部提示層不攔截點擊。
6. 不修改 `BlackMarketPage.tsx` 的資料與 React 邏輯、黑市排程、價格、購買或出售結算、卡牌規則、存檔、路由、世界時間。

## 使用者 Merge 後實機驗收（CI 不等於視覺測試）

1. 桌面 Chrome / Edge，720×1176 與 1280×800：商品陳列從對話下方開始並延伸至購買／出售按鈕上緣；人物、對話和時間還看得到，最少比舊版本多出數列可見卡片。
2. 390×844、360×740、320×568：390 三欄；360、320 兩欄；卡片名稱／價格間距與邊框不擠、最底部提示不壓到交易選項，必要時只在商品內捲動。
3. 比較最長商品名稱、卡牌與物品 SVG／emoji，確認沒有變形或字母直接貼框；完整名稱仍可在商品詳情看到。
4. 所有／物品／卡牌／更多條件、購買／出售模式、商品詳情彈窗及各種不足舊幣／不可賣條件照舊。
5. 在商品上使用滑鼠快速垂直拖曳、滾輪、鍵盤，上下捲動仍順暢、不誤觸商品；手機上下滑動保持原生。
6. 底部版本號／設定／返回主畫面不被蓋住。若窗口極矮則允許商品區內捲動，禁止資料或操作被裁掉。
