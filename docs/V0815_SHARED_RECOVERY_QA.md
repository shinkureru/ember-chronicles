## 實作細節

1. `src/styles/_v0815-shared-recovery-preview.scss` 於 `main.scss` 最後匯入，提供明確可重用的 `recovery-preview-card` 與 `recovery-preview-meter`，以及 `--recovery-meter-height:6px`、字體與內距 token。所有雙色目前值及淡色變化段在兩個畫面均使用相同 6px 條高、相同數字尺度、圓角和背景。
2. 沿用健康/生命飽和紅 `#ef5264` + 淡紅 `#ef9ca6`，體力 `#54b59f` + `#a9dbcf`，診所疲勞 `#a08cc5` + `#c4b4df`，其他診所負面條仍保有既有紅粉色。只改外觀，**不改原來 before/after 計算、區段百分比、ARIA、治療/休息費、時間和資源限制**。
3. 旅店休息預覽：兩張過大的 HP/體力卡改成「左標籤／右現在→預測」一行，下方接短雙色條與恢復小字，卡片自動高度；三種床位選擇縮到約 51px，建議區內距及上下空白縮小，整個彈窗用 `height:auto`、有最大高度，優先自然貼合內容，不再固定佔用 92dvh。
4. **舊幣不足問題的結構修正**：`inn-rest-cost` 與舊幣不足訊息搬到獨立 `inn-rest-dialog__checkout`（內捲動與 footer 之間）保留固定文字區。無封鎖時仍渲染等高度的隱藏空狀態；有封鎖時顯示真正的 `getTownServiceLock` 文案。底部兩個按鈕固定，不因出現／消失警示而重新佔用捲動空間；僅極矮裝置的「預覽內容」可滾動，不裁切底部操作。
5. 地下診所：沿用 v0.8.12 單欄雙色條設計，套同一 6px token，縮小小卡內距、前後數值字級、預計結果間距；診療計算與每日委託／藥房 Tab 不更動。
6. 手機小寬度(365/360px)與短高度(620/460px)有保護條件；超長提醒可換行，不採狹窄頁面隱藏費用、價格、警告或按鈕。保留 desktop 滑鼠拖曳、觸控原生捲動、鍵盤 tab 與 Escape 關閉。

## 使用者 Merge 後手動 QA 矩陣

1. 旅店在 **720×1176 / 1280×800 / 390×844 / 360×740 / 320×568 CSS viewport 對應等效尺寸** 開啟；三床位切換，看 HP／體力是否維持完整現在→恢復值、6px雙色條與 +N 小字；一般尺寸應盡可能不用拖曳即可看到全部內容。
2. 把舊幣降至 **0**：切換安靜單人房，應出現「舊幣不足，需要 40 枚」；同一底部 checkout 空間出現警告，footer 的「暫時不休息／確認休息」不會跳位、警告不疊按鈕、確認不可點。
3. 舊幣充足但體力/生命已滿；每日休息 2/2 達上限：預覽 0 恢復不虛構、禁用原因如實顯示、畫面完整。
4. 小到 320×568、橫置矮視窗 600×360 或 200% 文字放大：可以只在 preview pane 捲動查看，checkout 和 footer 不被隱藏，無不必要的多重捲軸。若超長警示換行，仍可完整閱讀。
5. 診所治療「外傷清創與包紮」6/10→10/10、外傷 6→4，紅/粉色短進度條與結果數值可讀；其他療法如體力/疲勞/感染、負面值下降也有正確雙色段。每日委託、藥房無版型退步。
6. 使用滑鼠拖曳、滾輪、手機觸控、鍵盤操作、Esc、X、背景點擊關閉，及確認休息的動畫/時間/金額/每日次數，必須功能正常。
