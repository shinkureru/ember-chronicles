## 資訊架構
- 七個頂部頁籤（裝備＋身體＋思維＋社交＋城鎮成長＋NPC記憶＋故事）改成五個（全身裝備／屬性／城鎮成長／NPC記憶／人物故事）。
- `src/features/player/characterSections.ts` 是唯一的頁籤與三類屬性列表定義；18項 attribute ID 與原本完全相同，每組6項，原永久屬性等級與加點按鈕仍能獨立操作。
- 新「屬性」同一內容頁有一次 XP／Lv／剩餘點數，下面三組分區：身體與生存、觀察與思維、社交與心理。頂部快速定位鍵可找到相應分區。**本批為資訊架構施工，18項太長時只捲動內部主內容，不將全部內容裁掉或誤稱完成後批的一頁式目標。**
- 五個頂部等寬按鈕、各自對應內部內容 section；原全身裝備換裝/卸裝、城鎮訓練與委託、NPC敵意與敗北記憶、職業故事均保留。不修改 `GameRoutes` 冒險期間的路由封鎖。
