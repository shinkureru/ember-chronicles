## 本批內容
1. `CharacterPage.tsx` 裝備頁原內嵌 JSX 拆成 `CharacterEquipmentPanel.tsx`，其餘五個頁籤入口/內容原封保留；人物圖隨已裝備的物品更新。
2. 七槽 `head/body/arms/legs/mainHand/utility/accessory`，舞台左3右4；選擇部位亮銅金外框，空槽與有裝備槽不同外框，完整裝備名與磨損說明保留於 `title`、`aria-label` 或物品詳情。
3. 六個 Stats 均從真實 state / 引擎讀取：HP now/max、ST now/max、`getEquippedDefense`、移動能力、觀察力與心理韌性。遊戲沒有真正的 CRIT/EVA 數值，所以不假造。
4. 下方 Inventory 合併**背包+倉庫**的實際物品數量，物品種類分類「全部／裝備／物資」，物品卡 `ItemArt`、數量與已裝備標示。遷移存檔裡只有穿戴、沒有背包數量的物品仍可顯示。最少12個空格呈現；物品超過能展示的格子時，**僅商品格子自己捲動**，舞台和 Stats 不走位。
5. 先點七部位決定裝備目標，再點物品開詳情；**只有按「裝備到部位」才會 dispatch**。具可讀禁用原因：不是目前部位、已穿戴、另一部位已使用、倉庫轉背包超過15kg、無物品、非避難所。原本 reducer `EQUIP_ITEM`／`UNEQUIP_ITEM` 的權限與狀態變動仍為最終判準；本批不修改存檔 schema 或引擎。
6. `_v0817-character-equipment-board.scss` 最後載入；一般 320/360/390/720 寬畫面顯示整頁主體，無主畫面捲軸。窄/矮視窗用 `minmax` 與 `max-height`/內層捲動降級，避免裁切操作。物品詳情 overlay 有 Escape 關閉及焦點高亮。
7. 版本 package + lock 更新 0.8.17；新專項 `tests/v0817-character-equipment-board.test.ts`，舊 v0816 原始碼位置檢查調整為新元件，並將歷史固定版本號改為 0.8.x。永久交接檔同步更新。
