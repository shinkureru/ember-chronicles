# v0.8.18｜人物檔案 18 項永久屬性的一頁式高密度版型

## 開工核對與界線
- 2026-11-13 基準：`main` `70be35a7f317ca59ab84fd614031faf6f0bbed8c`，PR #43／v0.8.17 已 Merge，Pages 部署成功；開工前 open PR = 0。
- 唯一分支：`ui/v0.8.18-compact-character-attributes`，對應 `docs/UI_COMPACT_REDESIGN_ROADMAP.md` 第5批。
- 本批只重設**已合併的屬性頁** UI：三類 18 個永久屬性。第4批裝備頁、本次之外的城鎮成長／NPC 記憶／人物故事、休息／診所、卡牌系統不更動。存檔、角色屬性、XP／加點規則與世界時間引擎完全不改。
- 原本 18 項各自有「永久成長屬性」占一行、全形升級按鈕占第二行、三個分類捷徑占高度且主內容垂直捲動；本批將它們改為緊湊的「名稱＋等級/20＋單獨『＋』按鈕」橫向單列，讓大多數手機一屏完整顯示。

## 排版與互動
1. 屬性頁頂部保留簡潔標題、等級 Lv、目前 XP/本級需求、可分配點數及 5px XP 進度條。用 `role="progressbar"`、aria-now/max 及 `output aria-live` 支援資訊讀取。提示文字清楚說明每次使用 1 點加一級及最高 Lv.20。
2. 三個分組仍依 `ATTRIBUTE_GROUPS` 真實六項清單，不另行硬寫第二份屬性 ID：身體與生存／觀察與思維／社交與心理。每組顯示目前累計等級/120，為原本6個屬性最高20的算式結果，絕不增添引擎數值。
3. 手機寬（小於 540px）為**三組上下排列、每組兩欄×三列**，共 18 個 30～32px 的操作小卡；較寬版（至少540px）為**三組並排、每組單欄六列**。控制各組 header、內距與格線，維持深色帶溫暖金/紅灰風格，數字採等寬排版；完整屬性名仍保留於文字 title／加點 aria-label。
4. 原 `ALLOCATE_POINT` 仍是唯一加點操作。屬性20級、沒有點數、非home會 disable，title 與 aria-label 說明原因，滿20顯示打勾符號。加點後 18 目前值、各組累計、剩餘點數與 HP/ST 屬性增益依 reducer 即時變動。
5. 移除三個重複的「跳到分類」捷徑（新版三組本來就同時顯示）；縮掉冗長的每卡副標籤，保留單一簡短全域加點說明。特別短（如320×568／600×360）或 200%文字縮放時，**只允許屬性主面板局部捲動**，不能把＋鍵或分類列裁掉。主選單頂部五頁入口不動。
6. 新增 `src/styles/_v0818-compact-character-attributes.scss` 在 `main.scss` 最後載入，只覆蓋 `.character-v0818`；沒有全域改動裝備、城鎮成長、NPC、故事、任何單雙色條。

## 自動驗收
- `npm run build` 需成功完成 TypeScript、Vite、Sass。
- `npm test` 需所有既有 Vitest + `tests/v0818-compact-character-attributes.test.ts` 成功，包含三組18屬性完整性、分組排版、單點升級、沒點數／滿20／非home、HP/ST影響、升級 XP、可捲動退化與 ARIA。
- 更新舊 v0816 對「分類跳頁捷徑／加點條件文字」的檢查，改驗新的同頁組別容器、等效防護條件，**沒有移除跨分類實際加點的回歸測試**。
- CI 靜態 CSS 契約不能替代瀏覽器像素/實機驗收。

## 使用者 Merge 後人工 QA 清單
1. 1280×800、720×1176、390×844、360×740、320×568：一般直立手機應同屏完整看見 Lv、XP、點數與三組18個屬性及其加點鍵，不需要上下滑頁；320×568 放不下時只能屬性內容區捲動且沒有裁切按鈕。較寬的720頁寬三分組須排成三欄且無水平方向溢出。
2. 低點數0和點數夠多（1／18）：三組加點按鈕都顯示同樣效果；加點扣1、對應屬性+1、分組合計數+1、點數即時減少；扣完按鈕立即禁用，不能負數。
3. 把某屬性推至20（max）後對應加點鍵應呈現已達上限，其他未滿20可繼續升級。非避難所不可偷偷加點；屬性 HP/ST 上限加點仍提升角色當前值及上限。
4. 390×844 連續點選兩組不同屬性的＋鍵：整個版面不因數值由 9→10 或點數 1→0 而跳動；XP/等級進度一致。長分類名稱與字串不互相覆蓋。
5. 360×740、320×568 及 600×360、200%文字放大、鍵盤 Tab／Enter／空白鍵焦點跳轉、滑鼠滾輪和手機觸控滑動：內容可達、焦點清楚、不會遮住頂部五個主要分頁。
6. 回切裝備、城鎮成長、NPC 記憶、人物故事，各頁內容和操作仍照舊。
7. 使用者自行 Merge，CI 通過不代表實機排版已驗收。
