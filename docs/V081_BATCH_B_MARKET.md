# v0.8.1 Batch B｜黑市商品整齊陳列與拖曳

狀態：以 `feature/v0.8.0-rest-and-town-status` 為依賴基準的 `feature/v0.8.1-market-grid`，尚未合併 main。

- 原本每張商品卡片有由 index 注入的隨機角度和上下位移 `--offer-angle`、`--offer-y`，造成凌亂交疊；本批移除這些數值，改為穩定三欄固定格線，窄幅畫面兩欄。卡片高度一致、置中圖案、最多兩行商品名稱、固定價格/幣值區。
- 內容維持自己的有限高度，顯示部分下一排商品作為可拖曳的視覺線索；底部弱提示文字不攔截指標事件。
- 隱藏垂直捲軸，但仍支援滑鼠左鍵按住上下拖動、觸控滑動、滑鼠滾輪與鍵盤焦點捲動；拖曳和點選交易商品分開，避免誤觸。
- 預設購買、分類、擴展篩選、商人好感度、庫存/限購與真實購買/出售 reducer 都未改。
- 本批版本 `v0.8.1`，保留 Batch A 的所有功能、玩家存檔。
- 測試 `tests/v081-market-grid.test.ts`，需要真實桌面滑鼠與手機驗收 CSS 版型，下方露出部分卡片是否直觀；CI 成功不等於 UI 實機驗收。
- 合併次序：先 PR #26 Batch A，再本批 Batch B，再 Batch C（卡牌圖鑑）。
