## 這批版型
1. 頂部主標題精簡，三入口「功能／附加技能」、「攻擊型主動牌」、「事前準備」並列；原已解鎖種數／總種數、技能牌組20上限／攻擊5上限、全部／已持有篩選完整保留。事前準備原 `/preparation` 路由維持。
2. 功能型新增稀有度「全部／普通／稀有／混沌」和職業歸屬「所有／共通／記者／滲透者／騎士」兩列篩選。三維交集只影響顯示 ID，保留原卡牌擁有順序（已持有優先）。當前資料沒有混沌卡時應回傳原始空結果提示，不憑空增加內容。
3. 功能卡四欄緊湊格：稀有度、原圖或未持有鎖、真實成功率 +X%、資源 -Y、卡牌 LV、兩行中文名稱、該 LV 數量。各等級 I-V 有原本五種邊框色，區分稀有度和等級。格子可上下捲動，保留鼠標拖曳和點擊防誤觸；上下主導覽/篩選/返回固定。
4. 卡片詳細窗維持效果、故事、取得方式、職業限定、等級複本數、素材消耗和 `UPGRADE_CARD` 原本操作；功能型邊距和 icon 略縮，攻擊詳情不改。
5. 寬度320/360/390/720及桌面1280×800，高度844/740/568及短於490、200%字體縮放，優先將格子捲動限制在卡牌主區，不裁切三主入口和底部返回。篩選按鈕可換行，鍵盤 Tab/Enter/Esc、focus-visible 必須可用；`prefers-reduced-motion` 禁用可選過渡。

## 驗收案例
- 在記者、滲透者、騎士存檔各檢查一次：`全部` 包含未取得卡（鎖顯示），`已持有` 正確只剩自己的；選「共通」只看到沒有職業限定的功能卡。
- 「普通/稀有/混沌」與「記者/滲透者/騎士/共通」及已持有交集：不漏牌、不錯類、零結果的空狀態完整可見；每次切換都回到圖鑑格頂端，切回攻擊時不受技能額外篩選影響。
- 準備一張 LV.III 主卡、9張 LV.I 複本：圖鑑分成兩格、數量各為1與9；點擊兩種等級分別開啟對應詳情。升級時使用原本需求張數，資料更新即時且不更動存檔 schema。
- 點選功能型卡看原故事/取得方式/效果，切到攻擊型卡看原傷害/成功率/必要武器，再點「事前準備」確認原裝備選取/負重警告/進關沒有改變。
- 390×844 / 360×740 / 320×568 目視四欄卡字體、長中文名稱、鎖/數量/LV和底部按鈕；1280×800、720×1176 驗證全部欄位。短/窄/200%縮放若內容過多只捲動 Grid，不由於卡牌數量把其他區塊擠走。
