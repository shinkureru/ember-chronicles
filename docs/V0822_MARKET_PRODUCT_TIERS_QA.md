# v0.8.22 商品四階級顯示與買賣安全性驗收

## 開工基準
- GitHub `main` `b959b5df1a81b2290f9f6c1d77490f554be951c2`，PR #47 已合併、Pages 成功、open PR 0；本次唯一分支 `ui/v0.8.22-market-product-tiers`。
- 參照用戶圖1的密集黑市貨架。**本批只處理商品卡**：四階底色、商品等級/價格/數量/名稱、詳情展示。場景插圖、左側買賣 rail/轉動 icon、10秒台詞、輪班倒數屬後續批次，不提前修改。
- 舊 `ITEMS` 沒有 item-level/rarity；本批物品 `Lv.` 為*展示級別*而非遊戲能力，卡牌黑市複本顯示真實 Lv.1。真正交易價/庫存依原商人輪班及 reducer，不能因階級變動。

## 開發改動
1. 新純函式 `marketProductPresentation.ts` 提供灰/綠/藍/紫四階級，灰（普通物資/雜物）→ 綠（工具/醫療品/普通卡複本）→ 藍（防具/稀有卡複本）→ 紫（禁忌 chaos 卡複本，現有商人未必有供應）。不改任何 ITEMS/CARDS/schema。
2. 商品卡強制顯示上方 `Lv.N` + 分類、物品圖示、兩行商品名、真實舊幣價、`庫存 N`（購買）或 `持有 N`（出售）。商品總價依 `mode` 真實切換；購買模式卡複本原內部 `available=99` 只是不限供應 sentinel，不得誤顯示「庫存99」。
3. 詳情窗顯示同樣的階級/展示 Lv 與完整交易價格/剩餘供貨，原交易是否允許/不足金額/背包限重/保護物品/卡牌原卡限制都保留。
4. 新 SCSS `_v0822-market-product-tiers.scss` 後載入並使用 `.market-v0822__product--scrap/field/special/forbidden`；主要3欄 <=375px改2欄；小視窗降高度；商品清單原滑鼠拖曳/手機觸控/滾輪/鍵盤 focus 不改。
5. 版本 package+lock `0.8.22`；新 `tests/v0822-market-product-tiers.test.ts` 測所有商人商品有階級、UI四個欄位、原交易 reducer與庫存、裝備/卡牌複本數量、安全RWD。舊 v0821 測試固定版號改成0.8.x，保留先前戰前準備功能回歸。

## 用戶 Merge 後手動驗收
- 390×844、360×740、320×568，720×1176、1280×800：灰綠藍紫階級 class 正確，顏色能辨識但仍符合壓抑風格；商品文字/物價/庫存數不得重疊；過多商品時只捲貨架。
- 五位商人各自的購買與出售狀態，顯示真實商品列表。購買商品後庫存 -1、舊幣下降且價錢不因 UI Lv 改變；出售後持有量下降且舊幣增加；販賣不可出售目前穿戴/常用/保護或備戰的唯一必要武器。
- 滿背包(15kg)、舊幣不足、供貨0、原卡未取得、卡牌只有主卡沒有複本等情境，雖可點開詳情仍不可確認交易，原因必須與遊戲原運算一致。
- 稀有 chaos 若現有輪班商人未販售，就不會出現紫色假商品，四階樣式為未來真實卡資料預留；若需強制每商人都有四階，應另開遊戲內容與貨幣平衡需求，不能在本批憑空新增。
- 桌面拖曳、手機觸控與鍵盤 Enter/ESC，篩選「所有/物品/卡牌/可交易/已持有」及長商品名稱均維持可用。
