## 場景構成與效果
1. 舊版左右兩個獨立人物 SVG 和中央隔牆，改成一張使用者提供的完整「斗篷、防毒面具、黑市室內燈光」場景。底圖在 `BlackMarketSceneArt.tsx` 的 SVG `viewBox="0 0 960 536" preserveAspectRatio="xMidYMin slice"` 呈現，使場景寬度縮放或垂直裁切時光暈跟底圖同步對位。
2. 眼部紫色光暈（x335/y121及x384/y128），頭頂暖黃色燈（x529/y51）、左側冷藍／白色燈（x202/y67）。使用 SVG 漸層光圈與 CSS 透明度週期，**不使用JS計時器、不修改圖片本身**；避免額外 re-render、數值運算或流量。
3. `prefers-reduced-motion:reduce` 時三處閃爍動畫完全停止，光圈保留平穩低亮度。光圈及遮罩 `pointer-events:none`，不阻擋任何交易、商品卡或詳細資料操作。
4. 場景右上保留*當班商人真實姓名/職業* `vendor.name`、`vendor.role`，右側顯示原 `vendor.line`（此批尚不加入10秒輪播）；底左保留世界時段與 `worldClock`。**圖2中的斗篷人物是固定場景插圖；遊戲原五位輪班商人姓名、物品、價格、交易條件不改，不代表五個商人被合併成一個身分。**
5. 右下新好感卡顯示 `s.economy.blackMarketFavor/100` 真實數字，新增雙色進度條（漸層紫→粉），`role=progressbar`、aria-valuemin/now/max。以原黑市好感實際滿值 100 呈現，沒有為了對齊圖1虛構千分制。
6. 320px/360px/390px手機和短視窗小於700px/520px特殊排版。右側台詞可必要時獨立局部捲動、文字不外溢，頂部的商人姓名與右下好感不可互相遮住；底左時間標籤仍可見。

## 新增必守規格：下批 v0.8.24
使用者於本批明確補充：**切換「販賣」後，右側應顯示玩家「背包」裡實際持有的全部物品，而非僅顯示商人收購白名單，也不可混入只有倉庫持有的物品**。
- 背包中商人不收購的物品也要能看見，但不可交易，明確標示「此商人不收購」；已裝備/保護/必要武器與無持有量亦不得偷賣。保留商人收購限制的 reducer 驗證，不能擅自改成所有物品都能出售。
- 卡牌升級複本是遊戲獨立持有資料，不應把它們誤作實體背包物品；販賣中「卡牌」篩選可繼續處理已持有可售複本。
- 在 **v0.8.24 買賣左側切換與圖3 icon 動效批次** 連同這項資料來源修正，一起做全面回歸。這批 v0.8.23 不修改交易清單或 reducer。
