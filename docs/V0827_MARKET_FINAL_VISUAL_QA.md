## 修正一｜中文字體的黑色水平線
- 先前 `_v0825-market-dialogue-loading-polish.scss` 對小字疊了四組 1px 黑輪廓陰影 + `-webkit-text-stroke:.15px`，還用模糊過渡，容易造成中文字筆畫疊影/黑線。最終 CSS **覆寫 stroke 為 0、移除任何 blur/filter**、改成兩層較寬的柔和文字陰影（無背景、無對話框）。淡入只有 opacity，不動文字幾何。
- 用 Chrome/Edge 比較這次使用者截圖的「用完記得」等中文字（含引號、句號），實際 100%/125%/150%/200% 縮放與亮/暗場景，確認不再有黑色矩形/水平斷線、沒有字體抖動。不同瀏覽器字型渲染仍須以真實畫面驗收；CSS 測試僅檢查有覆寫，**不能保證視覺問題已在所有瀏覽器消失**。
- 十句/每10秒的商人自語、文字陰影可讀性、切班/背景頁籤計時清理仍保留。

## 修正二｜左 rail 縮小箭頭／移除「切換」
- 完全**移除 HTML 中心「切換」文字**；arrow DOM 僅 `MarketTradeSwitchIcon`，整條 rail 一個 button，`aria-label` 清楚提供當前及下一模式，Tab/Enter/Space 可用。
- SVG 的 180° 中心旋轉、購買/販賣上下互換、active 放大/淡色縮小保留。箭頭尺寸：一般 35px、<=375px 31px、短高 <=700px 31px、<=520px 27px；調整垂直空隙避免箭頭與上下文字擠撞。
- 點上/中/下均能切換模式、不造成雙次 toggle；不用附加另一個「切換」按鈕。快速來回買賣，最終文字/箭頭方向一致。減少動態效果下立即換模式。

## 修正三｜只有商品卡從左上→右下波浪彈跳
- 過去 `_v0825` 整個 `market-v12__table` 加 0.4s animation，造成**標題/篩選/貨架框一起跳**。本批後載入的 CSS 對買賣表格以 `animation:none!important` 關閉舊整區動畫。
- 每張 `filteredOffers` 商品卡新增 `market-v0827__wave-item` 及按**從左到右、由上到下的 DOM/網格順序** `index×66ms` 的不同 delay，最大1.848秒；每張單獨輕彈 580ms（translate Y -9px→+2px→0、1.6% scale），不同買/賣 animation 名稱保證切回時重啟。僅切模式後發生，初次進畫面無波浪。售完/禁售商品也保留原透明度且不會誤解鎖。
- 注意舊商品 SCSS 有 `transform:none!important`：新波浪刻意用獨立的 CSS `translate` / `scale` 屬性，不會被舊 `transform` 覆寫。保持 3 欄（寬度>375px）及 2 欄（<=375px），DOM 順序不變。
- 手動在購買↔販賣間至少各切五次、不同商品數（0/1/3/7/20+）；只有**商品卡**逐格彈跳，標題/篩選/整張表格/左 rail 不跳、商品點擊/滾動/捲回頂部不受阻；Chrome/Edge 確認 CSS translate/scale 個別 transform 相容性。禁用動畫的系統設定時 wave 完全停止。

## 修正四｜場景左側白色日光燈柔和光效
- 保留原圖 `960×536`、暖黃燈 `market-v0823__warm-light`、藍色 `market-v0823__cold-light`、紫眼 `market-v0823__eyes`；另加沿原圖白色日光燈方向的橢圓柔和藍白 `market-v0827__fluorescent-bloom`，中心 x189/y88、半徑160×50、旋轉13°；gradient 中心柔白、邊緣淡藍，**不描繪假的新燈管**。
- CSS 6.5秒一次緩慢亮度呼吸（opacity .18～.68），與舊藍燈7.2秒呼吸互不完全同步，無快速閃爍。原圖與光暈使用同 SVG viewBox，手機圖片裁切一起移動不會跑位、pointer-events none 不阻擋交易。減少動態效果時靜態 .35 opacity。
- 在手機320/360/390、桌面720/1280實際檢視是否對準圖片左上燈、是否遮過商人臉／右上台詞，且不干擾好感/世界時間。
