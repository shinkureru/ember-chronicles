# v0.8.2 Batch C｜4×5 卡牌圖鑑、五級色彩與複本分離

基準：以 `feature/v0.8.1-market-grid`（包含 Batch A）建立的第三批 PR，尚未合併 main。

## 已實作
- 卡牌圖鑑的主要瀏覽區改為四欄、依容器高度配置五列完整卡牌，超過 20 張才會有第六列部分露出；當收藏總量不足 21 張時**沒有必要造出假的下一列**。較矮螢幕卡片有最小高度限制，可能需多捲動幾列以確保閱讀性。
- 原先 `PageStepper` 和固定每頁 12 張取消。現在上下垂直滑動，保留滑鼠按住拖曳、手機手指、滾輪與鍵盤，隱藏可見捲軸。
- 每張卡下方顯示 `LV.2 貼牆移動  ×1` 形式；圖片／卡名／數量重整留白。所有 5 種**升級等級**獨立識別：LV1灰 `#8e939a`、LV2綠 `#52b986`、LV3藍 `#67a7f5`、LV4紫 `#b68af0`、LV5金 `#e4c374`。以卡框、等級標籤與淡色光暈為主，不讓整張卡變亮。
- 採常見 RPG 等級觀感：灰→綠→藍→紫→金。注意**卡片等級**不同於 `normal/rare/chaos` 稀有度。後者仍以右上小字標示，升級等級顏色與稀有度不可在邏輯上混為一談。
- **同卡不同等級真實分離**：目前 GameState 的 `ownedCards[id]` 僅記錄一張已升級主卡的 `level` + 未消耗基礎複本的 `copies`。若主卡 LV3×1、剩餘複本 2，圖鑑顯示 LV3×1 與 LV1×2 兩張獨立卡面；若主卡 LV1 且 copies=2，顯示 LV1×3。未擁有仍顯示鎖定卡，不虛構已持有其他高等卡牌；舊存檔不用遷移。
- 點擊卡牌查看所選等級的持有數量；LV1 升級素材頁的升級按鈕停用，避免誤將材料當成可升級主卡。主卡升級仍使用既有 reducer 與複本門檻，升級後彈窗同步跳到新等級。

## QA
- 確認卡牌四欄、正常視口五列、超過 20 張時下列部分露出。手機小螢幕文字不溢出；注意高度太小時優先可閱讀性。
- 滑鼠拖曳/滾輪/觸控上下捲動，不顯示右側捲軸，不誤點卡牌；點擊仍開啟正確細節。
- 用升級後有剩餘複本的存檔測試：LV3 主卡與 LV1 未使用複本各自顯示正確數量，不會複製假的 LV2/4/5 卡。
- LV1～5 灰綠藍紫金框線區分，獨立顯示稀有度文字，點進詳情依所選等級顯示數量。
- 已持有/全部、功能卡/攻擊卡切換時重置清單捲動位置，仍可檢視原故事與升級條件。
- GitHub CI TypeScript + Vitest 全通過後依 A → B → C 合併，Pages 版本 `v0.8.2`，實機驗收。
