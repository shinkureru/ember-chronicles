- [ ] 飢餓 0/5/20/69/70/89/90/99/100 各測一次：預覽顯示原始成本及**實際差額**，99→100 只增加1，5→0只減少5；永遠不顯示將大於100或低於0的結果。
- [ ] 飢餓70/90/100之後**下一次**非保證行動與撤退成功率 −4/−10/−16百分點，保證100%劇情選項不受此規則影響；警示須清楚可閱讀。
- [ ] 預覽與實際動作完全一致；取消撤退/未打開故事/頁籤切換、不能購買、無效訓練、無材料修理、負重超出、重複點擊同件裝備等均不應偷扣飢餓。
- [ ] 旅店恢復 HP/ST、診所五項治療、工坊損壞/完美修理、舊幣扣款、升級與材料、對話/好感、使用食物補給都維持原效果，不能因減少飢餓代價而偷偷降低生命恢復或提高價格。
- [ ] 失敗與撤退保留提示線索，撤退失敗另加戰敗代價（封頂100），回城/存檔/重開不多扣。
