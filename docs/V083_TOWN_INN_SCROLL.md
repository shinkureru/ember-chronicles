# v0.8.3｜微批次 1：城鎮展開狀態與出租床位捲動

**基準**：`main` commit `bc6ef7be04f5174328ad4c3ea2ecedc2ca3a5f3e`，已部署 v0.8.2。

## 修改範圍
1. 城鎮頁面帶有 `viewport-page`，既有 `src/styles/_viewport.scss` 以 `overflow:hidden!important` 禁止垂直捲動；展開四種負面狀態後下方設施卡被推至頁外。改以高優先級規則讓 `.app-main > .page-stack.town-v15.viewport-page` 在**頁面內部捲動**，並以 `useVerticalDragScroll` 支援桌面滑鼠按住上下拖曳，手機原生觸控、滾輪與鍵盤方向鍵。隱藏垂直 scrollbar，但內容與所有設施仍保留，不縮限文字。拖曳不能誤觸設施按鈕。
2. 出租床位舊視窗 `overflow-y:auto` 將底部取消/確認按鈕捲出畫面。改 `header + inn-rest-dialog__scroll + footer` 三部分：標題及底部兩個按鈕固定於彈窗，只有三床位選項／HP ST 預計回復／休息建議／價格與限制在中段自行捲動。高度使用 dvh 與短螢幕規則，不隱藏重要文字，無側邊 scrollbar，桌面可拖曳。
3. 不修改休息金額／恢復公式／每日限制、城鎮設施及任何存檔欄位。版本標示 v0.8.3。

## 驗收
