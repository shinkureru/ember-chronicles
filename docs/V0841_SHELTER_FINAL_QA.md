## 人工驗收：設計師必須親自在部署的 GitHub Pages 測試

狀態：**以下全部未在本次連接器環境執行實機驗收（待使用者確認）**。每項完成後可以勾選。

### A. 全新開始、封面、三基地（桌機Chrome及手機瀏覽器）
- [ ] 新存檔（設定→刪本機存檔並重啟）：全頁封面約1.1s，沒有只包在468px寬遊戲框中或底層露出舊HUD。
- [ ] 故事從第1頁起，右上「跳過 →」只略過故事文字，仍需走完三段強制教學必敗演示。
- [ ] 走完整三頁文字、再走教程3步，結尾戰敗**不損血、飢餓、舊幣或任何真實進度**。
- [ ] 三選一廢棄倉庫／廢棄公寓／地下防空室；倉庫顯示實圖，另兩座顯示**各自**待製作占位，不能借倉庫偽裝。
- [ ] 重新整理，只重播封面、不重播已完成的故事／教學／選擇；職業選擇不覆蓋先前基地選擇。
- [ ] 先選公寓，按「預覽倉庫家具建設」能測倉庫所有功能；返回公寓仍是本人原據點。

### B. 八家具自由建設與原生圖層
- [ ] 空屋是原始 `background_empty.jpg`；只有 bed 購入時只顯示床；只有 computer 購入時只顯示電腦。
- [ ] 連續 1→7 件購入，所有家具透明邊界、陰影、透視與 768×1376 設計師位置一致，負 x 不應被強行夾回。
- [ ] 按「重洗路線」後，**已有家具保留**，未購入的下件順序不同；隨機3件、5件、0–8件均不必補齊前置家具。
- [ ] 「自動建造」約每850ms增加一件；按停止後不再自動購買；8/8不會超購第9件。
- [ ] 8/8切 `background_full.jpg`，完全不再疊上8張原始家具 PNG；從8件移除1件又回空景+7張PNG。
- [ ] 清空家具不清除舊幣、物資、NPC記憶與章節進度；刷新後家具數與順序維持。
- [ ] 對同一組如 computer+bed+radio，無論先後購入順序，家具實際座標及遮擋一致。
- [ ] 無線電台／工作台／證物調查板／電腦等重疊區域只取前層，透明空白不觸發錯誤家具。
- [ ] 觀察「左下料理台、床陰影、調查板去背」在每個混搭中是否自然。若獨立 PNG 的影子與整體滿圖略不同，記錄截圖，不要未經同意擅改原圖。

### C. 可點擊設施／柔和引導／無障礙
- [ ] 已買家具上有圓形標記、可點 PNG 實體、下方有「已建設設施」清單；未購家具三處都不能誤開。
- [ ] 手指點螢幕上的家具標記，資訊面板自動帶入目前可見區；可查看、關閉，長畫面的下方區塊不會看不到。
- [ ] 以 Tab/Shift+Tab/Enter 操作全部已購設施及其返回/關閉，焦點邊框可見；清單按鈕至少44px高。
- [ ] 買電腦後才能模擬重要支線、買調查板後才能模擬新手指引、買工作台後才能模擬製作完成；重複同一事件不排隊兩次。
- [ ] 通知光暈沿原 PNG 外型呼吸，約3秒柔和發亮；重要提示可「忽略」或「檢視設施」，兩者都會消除當前提示並顯示下一則。
- [ ] 觸發提示後移除家具：立即停止閃爍並清除通知及設施選取；再次買回也不應自動重新出現已移除的提示。
- [ ] 全8件高畫質滿配 JPEG 時，八件仍可互動，但不應重疊額外實體家具圖層。
- [ ] Chrome 開發者工具禁用影像載入後，PNG Alpha 拾取可以失敗但標記與下面清單仍可操作，不能把透明矩形誤當家具。
- [ ] 開啟系統「減少動態效果」：家具光邊無連續閃爍、滿配切換與家具新增不動態；重要訊息文字仍可讀。
