## 本批可玩的流程
- 避難所主畫面固定單頁：上方標題 → **完整不裁切的倉庫或基地場景** → 下方四個入口。場景依螢幕剩餘寬高等比例縮放，沒有垂直拖動。
- 第四個入口「建設測試」打開底部內層 Drawer，內含家具清單、已有家具資訊、三種提示示範、隨機/順序/全配測試、必要時職業選擇；Drawer 自身獨立捲動。家具場景點擊時亦會打開該面板。
- 點第一個「城鎮設施」進 `#/town`；原三段拼圖作完整背景，**由上到下三個高度均等**的毛玻璃點擊區：外環高架區（旅店、公告欄、開發中），蒸霧商街（澡堂、食堂），舊城核心（診所、工坊、酒館、訓練場）。
- 點任一區進 `#/town/outer-ring` / `#/town/steam-street` / `#/town/old-core`，其各自圖片真實存在，顯示清楚的設施清單與返回；此批服務按鈕是**詳頁骨架**，正式互動下批接上。
- 原本所有真實城鎮服務保持在 `#/town/classic`。從總覽頁/詳頁提供入口，避免在轉換新路線期間失去診所、食堂、工作台等原能力。
