# v0.8.44｜金屬・微光 UI 設計實驗室 QA

2026-11-15｜第六輪五批中的第3批。**本批只交付可重複使用的元件與 Showcase，未將它們大量覆蓋既有畫面**。

## 直接進入展示頁
1. 保留原玩家存檔，正常走完已完成的開場流程並回到避難所主畫面。
2. 點「設定」→「UI 實驗室」→「進入 UI 設計實驗室」；或在開場流程已完成且不在任務中的狀態輸入 `#/ui-lab`。
3. 在展示頁上移動滑桿、切換動畫與粒子、點選商品格，不應扣除舊幣、產生卡牌、購買商品或更改生命/體力真正數值。展示頁有返回設定與避難所導覽。

## 三組元件
- **第一組：光條** — HP 初始示範 1250/1000、體力550/900；HP顯示突破上限+250，視覺填充仍100%，也能滑到0／中間／滿／超額。小亮點跟隨進度前緣，微火花不該濺出到其他面板；切換「柔光動畫／粒子」各別生效；`prefers-reduced-motion` 關閉時全部粒子停用且圖條仍看得到。
- **第二組：正方商品格** — 灰/綠/藍/紫/金，選取後高亮與文字說明同步；卡格本體正方，不因卡名長短被拉成長方。紫/金只有微弱流光，不大面積閃爍。**金僅樣式預留，沒有真實掉落/稀有度規則**。
- **第三組：銀色邊框** — 主框有雙層細線與較深陰影、次框較簡潔、輕框低權重；對比應清楚，不要所有標籤與小按鈕都有巨大銀框。
- **可重用元件**：`src/components/ui/LuminousProgressBar.tsx`、`SquareRaritySlot.tsx`、`MetalFrame.tsx`；顏色與純函數 `urbanUiTokens.ts`；CSS `src/styles/_v0844-urban-ui-showcase.scss`。**不**改 `src/components/StatBar.tsx` 真實 HUD，也不會加入下輪決策前的正式遊戲介面。
