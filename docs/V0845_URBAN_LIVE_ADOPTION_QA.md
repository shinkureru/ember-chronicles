## 部署後人工操作（此欄尚未由本次 GitHub CI 驗證）

1. **黑市**：選擇買入／賣出，五位商人輪班，點不同商品看灰/綠/藍/紫美術底框；原價格、庫存、持有數與 Lv 標記要完整。點商品仍開原詳情，確認買賣能更新真實舊幣及背包，缺錢/不收/已賣完等仍不能交易。
2. **牌庫**：功能牌與攻擊牌都要顯示對應正方底框、升級等級、數量、攻擊傷害/武器條件。使用原過濾、向下捲動，點到不同格子仍會開對應 LV 詳情；升級/取消/返回照舊。
3. **關卡技能手牌**：進行原強制新手章節或測試章節，保持手牌每列三張、鼠標拖曳/觸控滑動；不足資源或技能不相容仍反灰，選擇技能實際更新預測數值與結算。
4. **HUD**：HP/體力數值在0%、50%、100%位置時看起來不會被前緣光澤遮住。飢餓、膽量、職業資源、疲勞、溫度、負重仍能在狹窄直式畫面辨認。
5. **城鎮場景**：外環高架區、蒸霧商街、舊城核心三張完整原圖仍正常顯示；低強度霧氣不會讓圖片整體白掉；開店熱點微微呼吸、打烊為靜止。點場景標記與清單皆能開8種原始服務。
6. **低動態與低電力**：模擬系統 `prefers-reduced-motion:reduce`，確認紫框流光/煙霧/熱點呼吸/HUD 微光完全停止；主要流程不需要特效才能用。
7. **裝置矩陣**：Windows Chrome/Edge、Android Chrome、iOS Safari，遊戲區 320/360/375/390/430px，低於 590px 的短螢幕、200% zoom、手機橫放；檢查黑市商品格名稱/價格不被擠掉、牌庫每列4格仍可看到資訊、手牌能滾、城市圖片不被裁掉。
8. **舊遊戲流程與資料**：重開遊戲驗證原避難所空屋/全滿直接切圖與8家具、回城鎮真實台北時計、黑市輪班、角色裝備/倉庫、任務防跳 URL、曾存檔資料完整保留；UI Lab 原 5色展示與動畫切換仍能使用。
