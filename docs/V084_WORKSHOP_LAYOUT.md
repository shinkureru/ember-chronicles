# v0.8.4｜微批次 2：修理工坊一致尺寸

基準：上一批 `fix/v0.8.3-town-inn-scroll`，先合併 PR #29 再處理本 PR。

- 修理工坊先前只有 `max-height` 沒有固定高度；裝備詳細資訊很多時整個視窗長高，空裝備時縮短，手機底部被壓住。現在視窗整體 `height:min(92dvh,850px)`，短螢幕按 dvh 縮放，**有裝備與沒裝備同尺寸**。
- 標題、工坊場景與底部「返回避難所」固定，只有四部位裝備卡、耐久和修理資訊的中段容器垂直捲動。保留電腦滑鼠拖曳／手機手指滑動／滾輪／鍵盤，隱藏垂直捲軸。
- 預留裝備名稱、受擊數、修理方案及長句提示空間；沒有裝備則在同一容器顯示置中的導引卡。
- 不修改裝備防禦、受擊損壞、工坊修理或升級計算、購買費用、存檔。
- 驗收：以相同視窗尺寸截圖「手臂有工作手套」與「腿部無護具」，確認外框上下高度、底部按鈕位置一致；手機短螢幕向下拖動可看見修理/精工改良按鈕；文本不穿透 footer。CI 必須通過。
- 下批：`v0.8.5` 地下診所，精簡就診摘要與各療程前後狀態，不增加完整人物條。
