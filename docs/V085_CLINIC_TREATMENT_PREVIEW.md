# v0.8.5｜微批次 3：地下診所「就診重點」及治療前後預覽

基準：`fix/v0.8.4-workshop-dialog-layout`，須依序先合併 PR #29（城鎮/床位）與 PR #30（修理工坊）。

## 設計決定
地下診所**不需要再複製城鎮的四條完整狀態進度條**。診所的核心任務是協助玩家挑選需要的療程，因此改為：
1. 在「診療」分頁頂部放一條小型「目前需要處理」摘要。只顯示**有缺損的生命與超過 0 的外傷、感染、中毒、疾病**，不顯示無異常的 0 層狀態。
2. 在每張原有療程卡內，直接列出真正會改善的 `目前 → 預計改善後`，生命／體力有最大值單位，外傷/感染/中毒/疾病/疲勞顯示數量前後及 +/− 差值。完全沒有可改善項目就顯示簡短提醒，禁止憑空宣稱療效。
3. 沿用既有 `clinicTreatmentPreview(s,id)`，新增純衍生 `clinicTreatmentOutcomes`；兩者和 `TOWN_SERVICE` reducer 同源，療程卡沒有額外計價/施作邏輯，不改療程數值、金額、判定、存檔、藥房或每日任務。僅呈現**直接治療效果**；所需時間還可能提高飢餓與（非疾病療程的）疲勞，文字明確提醒。
4. 介面：診所既有捲動內容內部增加小型診斷摘要 + 每卡兩欄治療差值，長文字可換行，移動版自適應，不增加另一層彈窗。原三個診所分頁都保留。

## 驗收案例
- 生命 7/10、外傷 3、其他狀態 0：頂部顯示生命與外傷，不塞滿零值；外傷清創預覽「外傷 3 → 1」，生命未滿時額外顯示真實 HP 增加。
- 感染 1、疾病 1：預計結果最低到 0，不會負數；無感染時感染治療不可按並顯示沒有可改善項目。
- 已滿血：一般診察不會假裝恢復生命，按鈕依原鎖定邏輯不能操作。
- 滑鼠拖曳與手機捲動診所卡片，確認新增資訊不蓋住 bottom bar／治療按鈕，長療程名稱、文字不跑版；每日任務、專屬藥房仍正常。
- `tests/v085-clinic-treatment-preview.test.ts` 逐項比對真實 `TOWN_SERVICE` reducer 治療前後結果。CI 通過才合併，手機／桌面人工驗收另行進行。
