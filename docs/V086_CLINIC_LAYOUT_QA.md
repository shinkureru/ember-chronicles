# v0.8.6｜第一批：地下診所介面精簡與電腦拖曳修正

## 本批範圍（**僅診所，不碰其他功能**）
1. 診療頁的「目前需要處理」縮成一條精簡狀態列，只呈現低於滿值的 HP 與非零的外傷／感染／中毒／疾病。保留原療程、收費、禁用條件，不重複城鎮完整狀態面板。
2. 每張療程卡改成和出租床位相同的「目前 → 預計治療後」數字＋雙色長條：目前保留值為飽和色、此次變化為同色系淺色。HP 紅、ST 綠、疲勞紫；外傷等異常狀態，飽和色表示治療後仍剩多少層，淡色表示這次移除多少層。維持柔和長條過渡效果。數值直接來自 `clinicTreatmentOutcomes`，沒有重新寫一套療效公式。這是**直接治療效果**；時間帶來的飢餓／疲勞改變沒有被算進療程預覽。
3. 診療／專屬藥房／每日委託沿用同一可捲動容器。診所專用 `useClinicDragScroll` 透過文件層級 pointermove/up 追蹤桌面滑鼠，避免卡片／按鈕跨區時遺失拖曳；拖動超過 6px 時禁止誤觸購買／治療。觸控仍原生 `pan-y`，滾輪與鍵盤捲動仍有效；切換分頁時回到頂部。
4. 「最近一則事件」只有進入診所後實際使用診所功能才顯示，不帶入之前的旅店訊息。該短句使用自然換行，不顯示獨立垂直捲軸；底部「離開診所」維持固定。
5. 版面只動 `ClinicDialog.tsx`、診所專用拖曳 hook 與新 `_v086-clinic-polish.scss`，不改遊戲引擎、價格、道具、任務、存檔結構。版本號 v0.8.6。

## 驗收重點
- 桌面用滑鼠在診療卡牌內**按住向上拖曳**，能一路看到第五項療程；切到藥房，按住卡片拖曳到最下面仍可購買。拖曳不能誤觸「接受治療」或「購買」。
- 手機手指滑動、桌面滑鼠滾輪、鍵盤可瀏覽全部項目；捲軸圖形隱藏但內容可到達，底部「離開診所」始終可見。
- 玩家 HP 6/10、外傷 6 層：上方摘要很短；基本診察顯示 `6/10 → 9/10`，進度條前 6 格飽和紅＋新恢復 3 格淺紅；外傷治療顯示 `外傷 6 → 4` 並以飽和／淺紅呈現保留與移除量。
- 打開診所時不能顯示舊的休息訊息；診所治療或購買後結果語句不出現短短的垂直捲軸。
- TS build + vitest 通過後才能 Merge；CI 綠燈只能證明自動檢查通過，**手機與桌面實際拖曳仍需使用者部署後驗收**。
