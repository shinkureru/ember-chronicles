# v0.8.7｜第二批：城鎮首頁止於八個設施按鈕

## 已實作範圍
- 以 main v0.8.6（merge PR #32）為基準，在獨立分支 `fix/v0.8.7-town-eight-facilities-only` 製作。
- 城鎮主畫面保留「舊街避難所」介紹、四條角色狀態與「查看影響」可展開區、八個設施按鈕。**八個按鈕即畫面最後內容**，移除原常駐 `town-v15__detail`（旅店等詳細區）與 `town-v15__footer`（重複的委託數、存檔提醒與前次事件），不會因預設選取旅店導致旅店資訊一直出現在八按鈕下方。
- 已有專屬彈窗的旅店、地下診所、修理工坊：保持原本彈窗及真實遊戲行為。
- 過去只能在主頁下半段使用的五個設施：情報酒館、訓練場所、公告欄、公共澡堂／洗衣店、公共食堂。建立共用 `TownFacilityDialog`，**點擊設施卡即開啟**；原本的服務費用、冷卻／不可使用原因、訓練屬性選單、公告欄承接與交付按鈕都遷入彈窗。內容長時可上下滑動，桌面滑鼠拖曳、觸控滑動、滾輪／鍵盤可用，底部返回按鈕固定。
- 彈窗有獨立角色狀態顯示與店家台詞；沒有操作就不再把其他設施的舊事件顯示在彈窗。使用服務後可查看本次回饋。
- 保留城鎮 `TownVitalStatus` 原本展開/收合功能與主城垂直拖曳。**不更動經濟、訓練、委託、裝備、存檔資料／結算引擎**。
- 版本提升至 `v0.8.7`。

## 驗收
1. 進入舊街避難所，展開身體負面狀態，向下滑到畫面結尾：只有八個設施卡片，沒有自動展開旅店、委託資訊、事件公告等重複內容。
2. 使用旅店、診所、修理工坊，原視窗完整可開關；取消不扣款；治療/休息/修理仍走既有結算。
3. 逐一點另外五個設施：情報酒館可購買時段情報；訓練場所可挑任一屬性、只允許一次；公告欄可承接與交付委託；澡堂可選洗澡/洗衣；食堂可選餐點與交談，沒有下方常駐內容仍可完整使用。
4. 電腦拖曳長公告欄列表、手機上下滑動，底部返回避難所按鈕始終可見；拖曳不誤按操作。
5. 建置、測試、歷史功能都通過後，仍需使用者手動 Merge 及瀏覽器驗收。
