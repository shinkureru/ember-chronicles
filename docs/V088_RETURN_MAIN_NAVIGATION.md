## GitHub Pages 驗收清單
1. 首先在主地圖（`/`）確認**不出現「返回主畫面」**，避免重複。
2. 進入城鎮，展開負面狀態、滑至第八個設施；畫面中的八個設施卡仍是最後一組功能；**最下方另有不覆蓋卡片的小型返回導覽列**，按下回第一章地圖。
3. 進入倉庫／人物檔案／設定，底部右側能看到相同標籤與圖示，點擊後正常回到第一章地圖。
4. 黑市：返回主畫面按鈕與原商人提示同列，不遮購買/出售與可拖曳商品；牌組：不蓋住卡牌等級／列表；事前準備：返回按鈕與開始任務按鈕並列，起始任務仍正常。
5. 電腦視窗、手機 360×640、375×667、390×844：長文字不跑版、按鈕不覆蓋底部內容；鍵盤 Tab 能聚焦按鈕。
6. 進入戰鬥關卡，畫面**不應出現直通主畫面的捷徑**。即使手動修改 URL，在冒險中仍返回關卡。撤退／死亡／勝利後仍照原有選項結算，沒有因此重設進度。
