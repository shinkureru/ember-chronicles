# Prototype v0.8 — 戰鬥辨識度與選項變化更新

## 本版已採用的設計原則

1. 普通物資、普通命中、體力消耗與每一步事件只寫入 HUD／紀錄，不再彈出一般通知。重大事件採用中央近方形黑色提示；危急時短暫震動。
2. 對峙場景強化敵人 HP 條與全身暗灰剪影模型。攻擊時從「確定使用」按鈕附近發射對應武器的 **原創 SVG 物件圖**，命中時搖晃、顯示傷害及輕微紅色傷痕；仍使用 v0.7 真正的 `CHOOSE` 結算判定。
3. 第一章每個場景有基本行動和新增替代選項池；依第幾次挑戰輪替，確保重訪不完全相同。玩家資訊與規則依同一個 `getVisibleActions` 判定，不會畫面選一組、引擎執行另一組。
4. 移除對「較差選項」的灰暗、雜訊、閃爍特效，保留缺少武器時真正無效的提示。每個需要判定的選項在選牌階段直接顯示 **未附加技能前成功率**。
5. 單卡確認畫面以**大型原創灰階物件圖**（鋼筆、記事本、相機、扳手、路線等）作為模糊背景；取消佔空間的崎嶇外框，前景文字使用高對比，敘述過長時僅讓文字區域內部捲動，不讓整頁捲動。
6. 附加技能按鈕移到右側確認操作旁，有符合規則可用技能而尚未附加時柔和發光。直接執行會提醒可附加技能，並提供「不再提醒」勾選，設定儲存在 `ember-skip-skill-warning-v08`。
7. 搜刮由引擎追蹤 `lootSearches`；桌面／貨架／口袋等各有次數上限。玩家第一次搜查後，行動選項旁就顯示剩餘次數；到零後該搜查選項不再出現。NPC 穿戴設備仍遵守跨重試的永久持有狀態。
8. 無論攻擊、交涉、探索等需要成功判定的行動，選牌時顯示基本成功率；若沒有成功判定的純操作則不顯示。

## 資料與程式分層

- `src/game/data/chapters/ch01-warehouse/sceneVariants.ts`：場景獨立選項池與輪替。
- `src/game/engine/lootLimits.ts`：搜刮次數及 NPC 實際剩餘裝備。
- `src/features/chapter/ActionObjectArt.tsx`：原創向量物件。
- `src/features/chapter/EnemyPresence.tsx`：敵人剪影、生命及受擊動畫。
- `src/features/chapter/AttackProjectile.tsx`：從「確定使用」座標飛往敵人的投射物。
- `src/components/GameFeedback.tsx`：重大通知判斷。
- `src/styles/_v08.scss`：可讀性、動畫與無頁面捲動排版。
- `tests/v08-choices-loot-feedback.test.ts`：重試變化、可通關路線、搜刮次數、重大通知。

## 存檔遷移與驗收

- 沿用 `ember-chronicles-prototype-v1` 存檔 Key。
- 舊存檔欠缺 `lootSearches` 時，依既有 `searchedSources` 做一次性遷移，避免舊版搜刮進度倒退。
- 自動測試：`npm run build` 與 `npm test`。
- 實機驗收：320×568、390×844、430×932、桌面直式框；按鈕可觸控、不出現整頁垂直捲動，技能提醒可勾選略過。
- 原創 SVG 是第一版模型與物件演出，未採用版權不明的外部素材。未來可替換成正式繪製或製作的高品質角色／武器素材。

## 非本次範圍

正式 3D 物理模擬、複雜 AI、第一章以外完整劇情、美術最終版本。
