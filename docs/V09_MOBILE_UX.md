# Prototype v0.9 — 手機使用體驗、功能大廳與交易 NPC 重構

## 本版關鍵決策（按使用者 2026-11-10 驗收回饋）

1. **戰後結束搜查**：點選「結束搜查」立即出現一次「繼續搜查／確定結束」確認對話框，跳過單張行動卡。確定時才呼叫 `CHOOSE`，保留既有物資。
2. **附加技能入口**：視覺上提高對比與尺寸，只有存在可附加技能而尚未附加時使用有效的 CSS keyframes 呼吸光暈；低動態偏好時停用動畫。
3. **選項不重疊**：每頁最多 4 項，固定 2×2 安全區，兩行文字折行；超過四項分頁。保留 v0.8 原本成功率資訊。
4. **選項專屬音效**：根據行動標籤與搜查來源對應快速跑步、潛行腳步、翻找衣物、翻紙、搜尋工具、交談、觀察等原創 Web Audio 聲音。
5. **功能入口統一**：主地圖保留城鎮、黑市、倉庫、人物、牌組五項功能；移除與主地圖重複的底部導覽及城鎮內的重複捷徑。所有非地圖頁面共用頁首「返回地圖」。
6. **設定只有一處**：保留頂部頁首設定鍵，移除主地圖設定入口。
7. **關卡節點直達事前準備**：主地圖移除底部大型關卡詳情卡與額外進關按鈕；點選可遊玩的關卡節點就進入 `/preparation`。下一個未完成關卡有上下跳動的箭頭提示，重玩以前已通關且有實作的關卡也同樣點該節點。已解鎖但尚未實作的關卡僅顯示製作中提示；未解鎖仍禁止點擊。
8. **事前準備不再獨立列在地圖功能**，僅從關卡節點進入。
9. **新手引導暫緩**，等使用者明確要求再製作。
10. **世界時間色調**：遊戲五個時段為早上 05–11、中午 11–14、下午 14–18、晚上 18–23、深夜 23–05。地圖、城鎮和關卡環境背景按同一遊戲時間換成五套深色調。
11. **人物頁六分頁**：全身裝備、身體、思維、社交、NPC 記憶、人物故事。預設是全身裝備，身形在大區域顯示，技能與文字分離，各分頁以手機可讀性為先。
12. **真實裝備提示**：在每個裝備槽下方顯示簡短效果。帽子防禦 +2、背心防禦 +10、手套防禦 +1，實際代入敵人攻擊的減傷。其他物品顯示道具用途，未實作的加成不虛構。
13. **黑市整合**：地圖「黑市」是唯一正式交易入口，城鎮不再重複列一個名為「地下交易所」的相同功能；黑市有五名不同形象（原創 SVG）與收購、販售清單的 NPC。
14. **真實商品交易**：`MARKET_BUY_ITEM` 與 `MARKET_SELL_ITEM` 檢查 NPC 交易清單、舊幣、背包重量、有限供貨，以及已裝備／受保護／攻擊牌武器的保護。交易成功才更動貨幣與庫存。卡牌交易保留高價格與複本限制。
15. **版本延續**：程式碼、測試、決策都寫入 GitHub；新 ChatGPT 對話先讀 `docs/AI_CONTEXT.md`、`docs/CHANGELOG.md`、本文件及 PR，再檢視原始碼、測試結果，避免從對話記憶猜測。

## 對應程式

- `src/features/world-map/ChapterMapPage.tsx`：地圖單點關卡入口與下一關箭頭
- `src/components/Frame.tsx`：唯一功能入口策略
- `src/features/chapter/ChapterPage.tsx`：結束搜查確認、場景色溫
- `src/features/chapter/ActionDecision.tsx`、`src/styles/_v09.scss`：四項安全布局與技能光暈
- `src/audio/actionCues.ts`、`src/audio/sound.ts`：動作音效
- `src/game/engine/rules.ts`：五個時間階段 token
- `src/features/player/CharacterPage.tsx`、`src/game/data/equipmentEffects.ts`：手機人物分頁與實際防禦
- `src/game/data/marketVendors.ts`、`src/features/market/MarketPortrait.tsx`、`src/features/market/BlackMarketPage.tsx`：五商人交易
