# Prototype v1.0-a — 城市地圖與任務節點整合

## 已實作
- 主畫面由原本小塊城市剪影改成寬幅原創 2.5D 深色都市 SVG 圖（`public/chapter01-city.svg`），保留夜間／清晨／正午／下午／晚上／深夜色調對應（實際五時段）。
- 第一章 12 個章節節點疊在同一張城市圖上，可左右滑動；關卡連線繪製在城市上。
- 一個小型 12 格編號導航，點擊數字時移動地圖視野到該節點；原有已通關、未開放與製作中的狀態仍保留。
- 下一個主要節點上方維持上下浮動箭頭；若內容尚未製作完成，標示「下一關 · 製作中」，不讓玩家誤以為可以遊玩。
- 五個功能入口（城鎮、黑市、倉庫、人物、牌組）移至城市下方精簡操作列，設定仍在主框架右上角，不重複。
- 玩家點選可遊玩的關卡節點，先進入事前準備；不變更遊戲世界資料或存檔格式。
- 圖片 URL 使用 Vite `BASE_URL`，同時支援本機與 GitHub Pages 子路徑部署。

## QA
- 320×568、390×844、430×932 與桌面直立視窗，整頁不得垂直滾動；只有地圖能左右滑動。
- 用手機觸控移動城市地圖、點 01 任務進事前準備、點未開發第 02 節點確認正確提示。
- 五功能入口單次點擊進入正確畫面，設定僅有一個入口。
- 章節縮略條可定位全部 12 個節點；`prefers-reduced-motion` 停止箭頭動畫。
