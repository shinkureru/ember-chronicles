# Prototype v1.0-b — 橫向散落選項及附加技能提示

- 取消 v0.9 的「最多四選項、固定 2×2」UI。
- 使用 **可左右滑動的自由散落文字區**；每一段各兩個長標題，距離依安全上下帶規劃，成功率置於標題下。
- 每段約 81% 可視寬度，下一段自然露出部分內容，**沒有頁數按鈕、沒有滑動提示文字**。
- 每次進入任務的嘗試次數和場景決定位置、歪斜角度與漂浮節奏；畫面重新渲染不會造成跳位。
- 第一章各場景新增實際可見 5～7 個選項，隨嘗試輪換，保留基本通關路線；有武器攻擊牌會額外出現。
- 有可用附加技能而未附加時，除了慢速發光，每三秒輕微晃動一次；沒有可用技能則不啟用提示。
- `prefers-reduced-motion` 會停止浮動及晃動動畫。
- 手機實機需檢查 320×568、390×844、430×932 的水平拖曳、尾端選項、文字不交疊與技能按鈕動態效果。

**依賴**：需先合併 v1.0-a PR #8；本 PR 為第二階段。
