# Prototype v1.0-c — 分時段黑市與實體攤位互動

## 商人出現規則
世界時間仍有五個時段，每個時段固定對應一位商人。**同一時間只會顯示一位**，沒有全部 NPC 一次展示的橫列：
- 早上（05:00–10:59）：灰手羅恩（機械修理師）
- 中午（11:00–13:59）：傷疤醫師（醫療商）
- 下午（14:00–17:59）：墨鏡阿黛（情報掮客）
- 晚上（18:00–22:59）：白髮信使（路線情報販）
- 深夜（23:00–04:59）：防毒面具（回收商）

共用 `src/game/data/marketSchedule.ts` 判定，目前交易時間取玩家的**世界時間**，非真實手機時間。交易 Reducer 也會確認商人當班及商品在商人清單內，防止透過舊按鈕繞過輪班。

## 攤位互動
- 上半部顯示當班 NPC 半身肖像、姓名、職稱和一句話，場景光線遵循世界時間。
- 下半部是有景深／桌面材質的交易桌，可點選商品物件，物件會稍微錯開。
- 購買、出售、卡牌三個模式各自顯示當班商人對應的商品／可交易物件；卡牌可切換買入升級複本或出售重複卡。
- 點選桌上商品後，**中央浮出**詳情卡，內有名稱、圖片式圖示、敘述、價格、庫存／持有數、商人、可否交易理由及真正的確認交易按鈕。
- 詳情卡可以關閉、按 Esc 退出；有減少動態效果設定時不漂浮。
- 完全保留既有黑市高價策略、好感度、負重、保護裝備及有限庫存。
