# Prototype v1.1 — 遊戲體驗第二輪改善

實作從已合併的 main（v1.0）接續，沒有重新初始化專案，也沒有變更存檔格式。

## 1. PC 地圖滑動
- 滑鼠拖曳時將 `scroll-behavior` 暫時改成 `auto`，避免原本 smooth 與 `scrollLeft` 每一幀更新互相干擾。
- 鼠標釋放後復原。左右箭頭仍維持平滑的定距捲動；手機原生手勢沒有改。

## 2. 行動選擇
- <=4 個原始選項：維持散落式文字，不強迫增加一層選擇。
- 超過 4 個：先用實際 action.tags 和攻擊卡屬性分成攻擊、交涉、搜尋、移動、觀察與生存類。
- 點選分組後，選項以所點位置為動畫中心放大、散開；五選項採 3+2，六選項採 3+3，7+ 選項使用不橫滑的可捲動網格。
- 不額外暴露成功率的分類層；具體行動維持原成功率和技能判定。沒有改遊戲規則。
- 移除橫向選項區，不再需要拖曳文字才能查看動作。

## 3. 附加技能提示
- 仍沿用 `skillCount > 0 && !skillId` 條件；新 CSS 將發光和三秒左右晃動整合在**同一個動畫**，避免兩套 transform／animation 互相覆蓋。
- 若無可附加卡或已附加技能，不閃爍、不晃動。

## 4. 全螢幕心理 OS
- 刪除原本故事面板內的「我的心聲」矩形區塊。
- 第一人稱心聲採固定定位、半透明、輕微雜訊與漂浮效果，偶爾出現 1～2 句；不擋按鈕。
- 心聲主要使用對應場景文本，狀態嚴重時才加入體力／生命／膽量／飢餓等對應語句；模態視窗及轉場期間暫停。
- 劇情全文功能仍能查看心聲記錄。

## 5. 五個場景
- `SceneArtwork.tsx` 有五組真正不同的原創 SVG：外圍物流站、監視器與貨櫃側門、辦公桌與檔案、警衛對峙長廊、衝突後搜查桌面。
- 同一關卡只有少量向量資料，且可因五個世界時間段同步套用色調，無需為每時段另外下載五張圖；不會造成龐大遊戲容量。
- 正式美術可替換此原型 SVG。

## 6. 真實錄音（Kenney）
- 已納入 11 段 CC0 OGG：多種腳步、布料、翻書、金屬、皮革小物、開門。來源授權詳見 `docs/AUDIO_LICENSES.md`。
- `sound.ts` 使用 AudioBuffer 解碼，會優先使用實錄；載入失敗或第一次尚未載入時改用既有 Web Audio 合成音效。
- 腳步快速連發、布料翻找、翻紙、工具碰撞等播放模式不同，仍受音效／總音量控制。
- 實機需耳測素材音量、音色與動作匹配。未收錄的叫聲、受傷等仍是合成音效。

## 7. 物資倉庫
- 物品清單改為明確的存入／領出箭頭，背包和倉庫都可打開資訊視窗。
- 新 `DEPOSIT_ITEM` 動作在 Reducer 實際移轉 1 件，遵守倉庫容量、已穿戴與常用保護規則，不會讓玩家的東西消失。
- 詳情視窗含類型、重量、持有數、來源位置、描述、常用設定及使用／移動操作。

## 8. 全螢幕過場
- 每次從準備流程進任務，先進入約 1.45 秒的黑暗章節轉場。
- 首次轉入對峙場景時播放 2.9 秒不同風格的敵人特寫：名稱、立繪、代表性台詞與座右銘。
- 轉場可略過，不影響判定；以後若擴大 NPC 系統，可將敵人自述移至 NPC 設定資料。
- `prefers-reduced-motion` 會停用大部分動畫，保留必要的文字資訊。

## 驗收
- `npm run build` + `npm test`
- 320×568、390×844、430×932 和桌面直式框；沒有整頁垂直捲軸。
- 請重點測試分類展開的六選項、不會蓋字；OS 不會擋操作；玩家能完成第一關並返回；倉庫物品守恆；音效與轉場。
- 不含正式美術動畫模型、新手教學，也不擅自變更遊戲故事與難度。
