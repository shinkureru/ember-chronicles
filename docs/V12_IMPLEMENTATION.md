# 《餘燼紀事》Prototype v1.2｜戰鬥與交易介面驗收

## 實作範圍
從 GitHub main 已合併 v1.1 開發。此次修改對應使用者 2026-11-10 的十點回饋；第 10 點屬城鎮功能提案，仍待討論，**本版本未偷加新的城鎮規則**。

### 1. 技能卡橫向區
- 桌面版可以按住空白或卡片區域，直接拖曳水平列表。達到至少 6px 才認定為拖曳，避免誤點卡片。
- 觸控裝置仍使用原生滑動。
- 不顯示「左右滑動查看更多」文字，卡片寬約 41%，下一張會從右邊自然露出一部分。
- 放開滑鼠後可繼續正常點選附加技能，套用成功率與資源數值。

### 2. 敵人回合
- 在實際的對峙場景中，玩家使用攻擊卡牌且敵人還站著時，敵人會從當前**仍持有**的工具中選擇一個進行投擲：對講機、手電筒、鑰匙串。
- 攻擊失手時對方保證反擊；玩家成功命中但未擊殺時，對方仍會嘗試反擊，命中機率暫定 68%。這些數字需要後續實機平衡測試，不作為定案。
- 擲出道具由畫面遠處由小到大飛近玩家，命中時顯示紅光、震動式閃光以及實際扣血數字；閃過則顯示閃避。
- **傷害和隨機判定由 Reducer 唯一決定**，絕不可由動畫再次抽籤；防具仍使用原來的減傷邏輯。
- 敵方道具目前屬行動演出，不因此刪除 NPC 物品或玩家資產。

### 3. 戰敗姿態
- 敵人 HP 歸零時倒下（旋轉、落地、淡出）約 1.7 秒，短暫保留原對峙環境。
- 搜查場景仍依原戰鬥規則解鎖，不額外增加一步「確認倒下」或改動測試依賴。

### 4. 任務開場與敵人亮相
- 入關過場 2.5 秒；敵人登場 3.4 秒。
- 登場畫面的人像是背景層，名稱、座右銘、台詞全部在人物前方，且提供深色背板確保可讀性。

### 5. 完成／失敗／撤退轉場與直接返回地圖
- 三種結果各自有背景色與文案；勝利 3.8 秒、戰敗 3.6 秒、撤退 3 秒，可略過。
- 原本章節後的靜態結算頁移除。結算轉場播完（或略過）才執行既有 `RETURN_HUB`，由 Reducer 進行掉落物自動入倉、休整、任務進度與記憶保留，再 `navigate('/')`。
- **不直接改 GameState.mode 以跳過結算規則。** 舊存檔在 `result` 模式載入也會進入結算轉場再返地圖。

### 6. 黑市新構圖
- 一級交易分類只有「購買／出售」；二級分類再選「物品／卡牌」。
- 場景上方改成 NPC 與主角的側面交易；中間有狹窄牆面與交易狹縫，強化非法交易感。
- 各時間固定一位商人，並依之前定案保留商品、有限供應與 NPC 特定收購需求。
- 桌上商品呈小角度錯落的可互動卡片；點選後仍彈出中央商品詳情，顯示庫存、價格、確認交易。
- 卡牌功能仍依原系統販賣升級複本，價格昂貴。主角模型抽到 `src/components/SurvivorFigure.tsx` 與人物檔案共用，且由同一份 `equipment` 決定已裝備物件。

### 7. 城鎮提案（未實作）
- 旅店、地下診所、修理工坊、情報酒館、訓練所、公告欄、澡堂與公共食堂。設計重點為世界時間、資源取捨與 NPC 記憶。
- 避免將黑市、物資倉庫現有功能搬入城鎮造成重複。

## 驗收項目
- GitHub Actions：TypeScript/Vite 正式建置與 Vitest 測試全過才合併。
- 390×844、430×932、320×568 直立視窗與桌面滑鼠：技能拖曳無誤觸、右側可預覽下一張。
- 對峙：實際使用鋼筆等攻擊卡，敵人正確反擊、扣血有數值與命中特效；防禦裝備有減傷；敵人被擊敗後有倒地畫面。
- 任務完成或失敗：等待過場或點略過後直接進地圖；背包、倉庫、關卡進度、NPC 記憶沒有遺失。
- 黑市：買／賣各有物品／卡牌選擇，商品可點開、商人當班限制存在，人物裝備更換時兩個介面一致。
- 減少動畫偏好（prefers-reduced-motion）保留重要資訊。
- 目前為原型 SVG 和 CSS 動畫，**手機實際操作和音效仍需玩家驗收**。正式敵人 AI、更多敵人物件及額外城鎮服務屬後續版本。
