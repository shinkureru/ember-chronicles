# 《餘燼紀事》Prototype v1.3 — UX + 世界時間 + 反擊節奏

此版本承接已合併的 v1.2 正式 main。沒有改既有版本 1 的 localStorage 存檔識別碼。

## 本次範圍

1. **黑市站位**：商人和玩家側面人物都背靠同一道牆、朝畫面外側，只有商人顯示職稱。保留雙方人物模型與裝備共用機制。
2. **全域時鐘**：GameProvider 單一計時器每真實 10 秒呼叫 WORLD_CLOCK_TICK (+5 遊戲分鐘)。背後分頁不偷跑累積時間；路由設定與任務內設定暫停；結果轉場暫停。世界時間跨日及黑市輪班依既有時間函式判定。手動行動產生的世界時間成本仍正常累加。
3. **黑市交易 UI**：初始只顯示購買／出售，點擊其一後交易桌上方出現「所有／物品／卡牌／更多」，更多可選「不限／已持有／可交易／補給／工具」。商人好感顯示在人物場景右下方的獨立資訊貼片；避免線條壓到文字。交易價格、商人進貨與好感機制未改。
4. **取得物品動畫**：新增 PickupFly，物品 icon 從畫面中央沿弧線縮小飛入右側開口背包、隨後消失；連續取得會排隊，不會覆蓋重大事件。透過 Reducer 的 lastLoot 或背包增加偵測搜查、交易與從倉庫領物；不額外增發獎勵。
5. **敵方延遲反擊**：攻擊牌的命中和敵人剩餘血量照原公式判定，仍存活才建立 enemyCounter。分階段：
   - waiting 2000 ms（玩家可選下一個行動，但無法結算）
   - windup 650 ms（敵人身體大幅晃動）
   - throwing 480 ms（物品從小變大朝鏡頭飛來）
   - hit 650 ms（命中扣血、全 UI 受擊震動、恢復狀態）
   反擊的命中與傷害在等待時只抽一次、並存入 GameState；實際扣血在 HIT 動作。END 清除事件，期間 CHOOSE／RETREAT 不可繞過。敵人致命反擊依原敗北流程。
6. **受擊震動**：game-frame 整體（畫面、文字、背景、UI）在敵方命中時 0.58 秒晃動，附柔和紅色邊緣暈光。
7. **物資倉庫**：存入改為 PackagePlus 箱子＋、領出改為 PackageOpen 開箱；保留清楚的中文 tooltip 與物品詳情視窗。
8. **快速功能切頁**：主地圖、倉庫、黑市、牌組、人物、城鎮等非關卡頁面使用 230 ms 的淡入／微位移／模糊消散效果；不加額外頁面。
9. **減少動態效果**：prefers-reduced-motion 可停止震動、位移、閃爍，維持重要文字訊息。

## 手機與 PC 實機驗收
- 黑市剛進入：只看到購買、出售；點擊才浮現二級篩選。
- 18:00 前後在黑市停留，NPC 自動換班而不遺留舊商品交易對話。
- 取得水瓶、工具、卡牌時看見物件飛入背包，連續兩件不互相遮蓋。
- 反擊時間：送出攻擊 2 秒後敵人開始甩動，接著才投擲，命中才整畫面晃動；中途無法連點快速攻擊。
- 手機與桌面、320×568／390×844／430×932 直立 UI、不需要整頁上下滾動。
- 轉頁特效在主功能中快速輕巧，不應有空白遮罩或操作延遲。
