# 餘燼紀事 v1.4 — 後巷的目擊者、滲透者、CC0 音效

## 製作完成範圍
1. 第一章第二關「後巷的目擊者」由預告節點改為可遊玩，經關卡地圖節點 → 事前準備 → 第二關流程進入；第一關已通關才允許選取。
2. 五個不同場景：抵達後巷、目擊現場、不可靠的證詞、被截斷的退路、最後的證據。獨立的輕量 SVG 場景圖與角色台詞，均有劇情選擇與第一人稱 OS。
3. 可選多路線：從觀察、繞行、訪談、證據交涉到正面交戰；環境搜刮來源不同、地圖時間成本、負重與拾取提示沿用 v1.3。
4. 同名選項在不同重試次數會更換額外候選（固定每次嘗試，避免重新渲染後洗牌）。`alleyNpc` 記錄獨立敵意／重訪／失敗資料，和第一關 `npc` 隔離。
5. 失敗保留物品、保證獲得新的後巷線索並提高下一次首次判定；完成後結算通往「無人接聽」的線索，將第三關節點解鎖（第三關內容尚未製作）。
6. 第三職業「滲透者」：四張專屬行動附加技能、一項被動、兩張需實際工具的攻擊牌、專用初始庫存、完整卡牌故事。原有職業和 18 個永久屬性仍保留。
7. 音效：實際新增 8 個 Kenney UI Audio CC0 WAV。相較 v1.3，點擊、選擇、確認、警告、檢查、對話等操作使用不同實錄音；其他特殊行動延續 Kenney RPG Audio CC0 或自製程序式 Foley。
8. BGM：後巷五組獨立的原創小調旋律、低音與氛圍聲；敵人現身切換緊張配樂，節奏更快且多聲部，不用未授權音樂。
9. 存檔鍵與結構版本仍使用 v1；舊存檔載入時補齊 `stageId=1` 與 `alleyNpc` 初始資料，無需重建玩家資料。

## 驗收清單
- 沒過第一關不能點第二關，過第一關後第 02 節點可進，仍不能進第 03 關。
- 選擇第二關 → 事前準備 → 全螢幕第二關轉場，看到正確場景、後巷敵人與配樂。
- 五段不同場景畫面、選項非固定且不會每次 React 渲染隨機跳動；攻擊選項與裝備檢查仍正常。
- 可採非戰鬥路線（觀察巷口 → 等巡邏離開 → 說服目擊者 → 收集證據 → 離開）完成第二關，解鎖第 03 關。
- 戰鬥敵人 HP 正確顯示、反擊兩秒預備和受擊動畫沿用；擊倒後可搜查。
- 第二關戰敗後 NPC 認出玩家，第 01 關管理員記憶不受影響；原有搜刮物不遺失。
- 新職業潛行加成可與調查記者、外送騎士明顯區分，所有專屬技能可附加於正確標籤。
- 行動、介面及 BGM 用原創／可商用 CC0 音訊；瀏覽器首次點擊前靜音符合自動播放政策。
- Windows Chrome 與手機瀏覽器直式畫面；狹窄 320px 下卡牌資訊可讀、音訊穩定無失控。
- GitHub Actions 通過正式 TypeScript/Vite build 與 Vitest。
