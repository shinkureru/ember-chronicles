# v1.5.1｜戰鬥數值可讀性、低血量平衡與物品辨識

本文件對應 `feature/v1.5.1-combat-hp-item-icons`，合併前僅是待驗收的實作，不能當成正式上線保證。

## 戰鬥數字

- 敵方擊中主角的「遭受攻擊 −N」保留約 2.75 秒；文字動畫在實際命中附近才顯示並停留約兩秒。
- 顯示狀態在 `ChapterPage` 持續留存，不會因為 `enemyCounter` 階段完成而立即取消；非致命反擊的規則結算時間維持原樣。
- 致命傷的結束過場延後，避免輸掉時數字瞬間消失；敵人受傷數字約 2.4 秒。
- 敵人被最後一擊擊倒，保留對峙畫面約 2.65 秒供玩家觀察數字後才換成搜查場景。
- 持續時間集中於 `src/features/chapter/combatFeedbackTiming.ts`；文字動畫仍在 `src/styles/_v08.scss`、`_v12.scss`。

## 生命與城鎮訓練

- **全新存檔**：主角 10/10 HP（原 100/100）。體力、膽量、敵人 HP、攻擊牌與裝備防禦先不變，避免本輪改動擴大。
- **已有存檔**：`GameState.version=1` 和 localStorage key 不變，首次載入將原 100 HP 基準按比例換成 10；例如 93/100 → 9/10。
- 舊版每次訓練增加的 5 點生命上限，轉換為新版的 1 點：例如舊 55/110 → 新 6/12。新增 `hpRulesVersion:2` 標記，避免重複縮放。
- 新版城鎮生命訓練每次 +1 HP 上限，取代舊版 +5。兩次普通 6 傷反擊可擊倒無裝備的滿血角色；防具與傷害減免仍有效。
- 戰敗既有的線索保底、裝備保存及 1 HP 脫困結果仍保留。沒有擅自加入永久損失。

## 物品圖案稽核

新增 `src/components/ItemArt.tsx`，為原本看起來不像本物品的圖示使用專屬向量輪廓；物品資訊頁、倉庫列表、黑市清單/詳細、取得物資飛入背包動畫共用。

首批 16 種替換：繃帶、沾水電線、工業膠帶、瓶裝飲水、短距離對講機、簡易急救包、舊式防護背心、暖暖包、訪客證、折疊工具、倉庫鑰匙串、破損照片、車號紙、值班紀錄、乾糧餅乾、破損皮手套。原本正確的鋼筆、相機、螺絲起子等仍可使用原生 emoji。

`bandage` 資料原先錯設為 🩺（聽診器），已替換為 🩹 作後備；主要遊戲畫面改用真正的**捲狀繃帶 SVG**。

未重新繪製所有卡牌、場景裝備及戰鬥投擲 SVG。本批修正以具體物品識別為範圍；未來若要全部統一美術風格，需獨立進行視覺驗收。

## 重要手動 QA

1. 以已有存檔的 93/100 HP 玩家載入新版，檢查首次轉為 9/10，再重整仍是 9/10，不掉裝備、金錢、任務進度。
2. 新角色從 10/10 出發；連續被 6 傷反擊兩次進入戰敗演出，掉血數字完整可讀。
3. 主角致命受傷時，等「遭受攻擊」數字正常消失後才進入戰敗過場。
4. 對敵人攻擊，包含非致命與致命一擊；`-N` 數字至少可看約兩秒，不被立即切換場景吃掉。
5. 到城鎮訓練生命上限，10 → 11 HP，重複當日訓練無效；舊存檔已訓練項目正確換算。
6. 倉庫、黑市及物品取得動畫逐個檢查 SVG 形狀。特別檢查繃帶、膠帶、電線、對講機不再錯用無關圖。
7. 確認手機狹窄直式畫面和使用者設定減少動畫時，字體與圖示仍清楚。
8. CI `npm run build` / `npm test`，加上 `tests/v151-combat-feedback-and-items.test.ts`。

## 暫不實作

- 戰敗金錢、裝備、永久能力或 NPC 關係的懲罰：仍在與使用者討論。
- 整體體力／膽量值降低、敵人全體 AI 平衡、每首 BGM 替換：後續小批處理。
