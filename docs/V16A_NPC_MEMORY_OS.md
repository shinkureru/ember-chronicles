# v1.6a | NPC 記憶與主角內心 OS

## 已寫入開發分支，尚待 PR CI、實機驗收

- 關卡主角第一人稱 OS 改成**同時最多一則**，選取時排除上一句、同一池去重；每則顯示約 3.9 秒，下一則在前次出現後 19–28 秒才會出現（較原本 11.5–20.5 秒稀疏）。
- 將 OS 的低生命／低體力判定改成當前上限百分比，避免縮到 10 HP 後無時無刻都顯示危險獨白。
- 各關 NPC 以 `combatDefeats`、`defeatMemories` 個別儲存。**只有玩家實際用攻擊卡把敵人 HP 打到 0，才建立一筆記憶**；交涉成功、逃跑、一般來訪不更動此系列心理 OS。
- 前十次 NPC 戰鬥落敗各有不同簡短心理 OS，並保留每次遭受何種武器手段、真實敵意與攻擊適應累計；最多顯示最近十筆（避免列表無限增長）。
- `npc.adaptations.fight` 每次戰敗增加 2，至多 12，該數值已被引擎的攻擊成功率預覽／結算共用。
- NPC 記憶 UI 在人物檔案直接列出簡短手段、OS 與數值變動，兩個 NPC 各自獨立。
- 人物故事頁不更改；使用者之後會提供核心故事，再做潤飾。
