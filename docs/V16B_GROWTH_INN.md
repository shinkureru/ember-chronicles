# v1.6b｜10 點體力、18 屬性零基礎、出租床位與等級 XP

> **開發分支設計與實作備忘**。待 GitHub CI、手機操作及存檔遷移驗收後才能認定發布。

## 目前實作範圍

- 新人物生命 10/10、體力 10/10，18 個永久成長屬性從 0 開始；膽量、飢餓、疲勞和職業資源保留獨立尺度，避免將生存狀態誤當能力點數。
- 舊人物資料一次性從舊 `80+` 體力與 `10+` 屬性轉換成 `10+` 體力和 `0+` 屬性；例：48/84 → 6/11 體力、原觀察 13 → 新觀察 +3。新增 `growthRulesVersion=2`，不重複換算，不刪資料。
- 既有原型卡牌行動成本曾以 80 體力撰寫，因此在引擎統一除以 8 並向上取整；提示和結算共用公式，避免角色第一關走一步就疲勞透支。
- 主角經驗值：每個遊戲日同一事件最多領一次；可從行動（含交談/搜尋/戰鬥）、關卡完成、城鎮服務、接取/完成委託、黑市實際交易及消耗品取得。每天另設 120 XP 上限，避免輪流刷不同活動暴衝。只有真正成功提交的遊戲動作才獲得經驗，UI 點擊與世界時鐘不算。
- 升級需求為 `40 + 20*(當前等級-1)` XP；升一級獲得一點可自由分配的永久屬性點，最多單屬性 20。可以在人物檔案的身體、思維、社交頁分配，並有等級與經驗進度條。
- 城鎮既有「專項訓練」仍然每天限一次，保持需要舊幣/時間的成長選項。生命/體力上限屬性升級各 +1（可獨立變化）。
- 出租床位採 **當前體力缺口比例** 推算回血，沒有將「1 體力換 1 生命」硬綁。例如生命 3/10、體力 8/10，普通床位實際為生命 5/10、體力 10/10；體力越低睡醒恢復生命越多，隨體力上限的變化自然伸縮。三種床位均使用同一純函式預覽和結算，計算方式見 `src/game/engine/innRest.ts`。
- 同一遊戲日最多睡兩次；普通、單人房、短暫打盹共用上限。操作前有詳細視窗顯示生命/體力變化、進度條、花費、時數、剩餘次數及目前距離恢復滿血所需體力建議值。
- B 偏輕度戰敗懲罰：剩餘 1 HP、至少一項外傷、耗費 2 小時世界時間，物品/金錢/經驗及關卡進度不沒收；維持每次失敗取得新情報。返回據點不再額外補血/補體力，否則床位失去實際作用。

## 注意及仍待驗收

- 後續卡牌、敵人平衡可能需要依 10 點體力重測；既有大數值加成仍採用原有設計。
- 升級 XP 的額度是本批原型可調參數，與整體 18 屬性成長曲線尚未完成長期遊玩平衡。
- 休息預覽顯示的是本次確定結算，建議玩家可先自然消耗體力獲得更多治療效率，但不要求故意耗費體力作無意義行動。
- 原有診所、工作坊等其他城鎮功能未全部重新平衡，下一批依實機體驗逐項調整。
- 人物故事由使用者日後提供核心劇情，不在本批次改寫。
- PR #17 的 OS 和 NPC 記憶在另一獨立分支，不能在本 PR 尚未合併時假裝已包含。

## QA

1. `npm run build && npm test` 及 GitHub Actions；必要時修正舊版期待數值與新規格的衝突。
2. 新角色 HP/ST = 10/10，18 永久成長值全為 0。
3. 舊進度和舊人物屬性一次性換算，關頁/重整均不重複觸發。
4. 3/10 生命、8/10 體力，普通床位預覽與實際結算都是 5/10 生命、10/10 體力。
5. 玩家升級後分配生命或體力，預覽在不同生命與體力上限仍合理。
6. 兩次租床位後，換床位不能規避每日上限；隔日重新開放。
7. 同一日重複交談或交易不提供無限 XP；隔日可獲得一次，全天不超過 120。
8. 戰敗與返城後保留低血量，時間變長，保留物資/線索；診所與床位可恢復。
