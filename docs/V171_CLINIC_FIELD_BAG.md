# v1.7.1｜地下診所與關卡內背包

> 本文件追蹤 PR v1.7.1 的實際程式與驗收項目。它建立在 v1.7.0（頁首版本、旅店、戰敗與敵人嘲諷）的分支之上，必須先合併前置 PR，才能將本 PR 併入 main。

## 地下診所

- 進入城鎮後點擊「地下診所」卡片，立即打開 **React Portal** 視窗，避免被固定高頁面裁切；提供自製 SVG 診療室場景、患者現況與三分頁「診療／每日委託／專屬藥房」。
- 診療預覽由 `clinicTreatmentPreview` 提供，與 `townActions` 結算共用：
  - 基本診察：生命最多 +3、20 舊幣
  - 外傷清創：外傷 −2、生命最多 +4、24 舊幣
  - 感染治療：感染 −2、生命最多 +2、32 舊幣
  - 中毒處置：中毒 −2、體力最多 +2、38 舊幣
  - 疾病診療：疾病 −2、疲勞 −12、28 舊幣
  - 若無對應病症，會提示不需治療；費用不足則按鈕禁用並顯示原因。
- 每日診所支線在三項物資委託間輪替：飲水、繃帶、急救包。當日先承接、帶足物資後交付領取舊幣與診所好感；每個遊戲日最多完成一次。好感最多 30，實際改善專賣藥品價格（最高降價 15%）。
- 四件診所專賣藥品及原始價格：無菌敷料組 44 舊幣、抗感染處置包 67、緊急解毒針 79、鎮痛藥盒 49。有限制每日庫存。物品有專用 SVG，使用時確實更改外傷／感染／中毒／體力／生命／疲勞。
- 診所數據存在 `TownProgress.clinic?` 可選欄位；老存檔沒有時使用安全的預設值，不重置舊倉庫和 NPC。

## 關卡內背包

- 關卡上方新增 **背包** 按鈕，任務中隨時可檢視目前背包負重、生命和體力。
- 「使用補給」僅列出實際放在 `s.bag` 的可用物資，預覽恢復數值，透過現有 `USE_ITEM` action 消耗一件並寫入真正的 GameState。
- 「更換裝備」按裝備槽列出目前背包的物品，使用既有 `EQUIP_ITEM` 與 `UNEQUIP_ITEM`；更換即時影響防禦計算。任務中不可直接從城鎮倉庫提取沒有攜帶的裝備；每次更換需 2 分鐘遊戲時間。
- 若敵人反擊正處理中，可檢視但不能使用物品或換裝，避免繞過反擊。任務完成結果畫面也不再接受操作。
- `previewConsumable` 和 `clinicTreatmentPreview` 都是**共用單一公式**，不能在 UI 自己估計不同效果。藥物從 100HP 版本的大額補血改成 10HP 版本的合理幅度。
- 模態視窗使用 Portal；使用 Escape 或關閉按鈕返回關卡。開啟後暫停一般世界時間跳動，但不停止已排定的敵方反擊。

## 待人工驗收

1. 點選地下診所，手機短螢幕可完整滑動治療、委託、藥房內容；SVG 場景正確顯示。
2. 診所五項治療所有預覽與實際結果一致，沒有症狀時不可誤收費。
3. 連續兩次交付同一天委託不會再領錢、好感和 XP；跨日會變換委託。
4. 專賣藥品 4 項圖示、價格、好感折扣、每日庫存、背包負重限制及舊幣扣除。
5. 任務中受傷後開背包使用無菌敷料，生命與外傷立即改變、物品確實 −1；敵人反擊期間不可消耗物品。
6. 任務中更換防護背心實際提高角色防禦；背包沒有的裝備不可偷從倉庫裝備。
7. 舊玩家存檔載入不丟物品、角色、任務；跨頁與重新整理後診所好感及每日進度仍存在。
8. GitHub Actions TypeScript、Vite 建置、所有 Vitest 必須通過；GitHub Pages 版號與短碼仍可辨識是否已部署。
