# v1.7.3｜個人戰利品、舊幣搜索、敵人專屬失敗反思

狀態：待合併的引擎修正分支 `fix/v1.7.3-encounter-loot-insight`。Base: `main` 於 2026-11-12 上午部署成功的 `a861f5ad03e89c8fa6f141b4b4a1f56081620edb`（v1.7.2）。

## 規則
- 搜索敵人口袋或卸下裝備，**必須在該次任務以真正武器攻擊將敵人生命歸零**（`flags.includes('won_by_combat')` 且 `enemy.health===0`），和平通過或潛行時不會顯示選項；`remainingSearches` 也獨立擋下試圖繞過 UI 的搜刮。包括阿忠的 `pockets`／`npcGear`，以及守望者 `alley_pockets` 和沿用此來源的各種重訪變體。
- 桌子、貨架、街邊紙袋、破牆、長椅帆布包等**不涉及敵人的環境搜索**照常可進行。
- 有效且未耗盡的搜索有 18% 機率直接找到 2–5 枚舊幣，入錢包、扣一次該來源的搜查上限，顯示拾取動畫。錢幣不放背包，無需負重；`npcGear` 確保不會被換成錢幣；這些機率和數量需要遊玩後再平衡。
- 玩家的**失敗反思**每個 NPC 分別計次，`npc.playerDefeats` 持久保留，彼此不重置。首次關鍵判定百分點透過 `insightByEnemy[enemyId]` 記錄、讀取與單獨消耗，不能轉移到另一名敵人。一般劇情線索仍可跨任務累積，但「失敗反思」不再計入全域線索命中率加成。
- 舊存檔的 `insightBonus` 只在缺少 `insightByEnemy` 時遷移到目前所選關卡的 NPC；不清除 NPC、進度或舊物品；往後只讀新的分敵人映射。
