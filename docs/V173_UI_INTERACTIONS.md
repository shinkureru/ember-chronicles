# v1.7.3 UI 第二批｜直式操作、技能資源與拖曳

分支 `feature/v1.7.4-ui-interactions`，PR #23：https://github.com/shinkureru/ember-chronicles/pull/23
依賴 PR #22：https://github.com/shinkureru/ember-chronicles/pull/22 。**先合併 #22，重新檢查本 PR CI 和 diff，再合併 #23；不得先直接合併到 main。**

## 修改
1. 旅店三種房型、恢復建議、按鈕文字預留一致的高度。長文字可自動換行而不擠壓其他元件，狹窄螢幕也有額外留白。一般 UI 往後應預估文字長度與繁中字型換行。
2. 關卡內「查看背包」移到場景畫面左側中段，保留文字、背景與對比度；不是頁首難辨認的圖案。入口仍開啟原本的 FieldBagDialog。
3. 附加技能維持卡片漂浮，但將容器改成三欄固定網格，優先容納兩列完整卡片；第七張開始可在下方露出一部分，引導向下滑動。支援手機觸控、滑鼠按住拖曳、滑鼠滾輪與鍵盤可捲動容器；隱藏直向 scrollbar。標籤刪除「資源消耗」，改為 `−數字 + 專屬圖標`。調查記者眼睛 Eye（洞察）、外送騎士閃電 Zap（衝勁）、滲透者足跡 Footprints（隱匿），在 HUD 與技能預覽同步。
4. 黑市預設進入「購買」並顯示當前商人商品；切換「出售」仍保留，重點商品區支援桌面滑鼠按住上下拖曳（拖曳不觸發選品），手機保留原生觸控垂直滑動，隱藏捲軸提示。
5. 閃避成功反饋改為場景上半部中央、大字、強烈對比，僅為不阻擋操作的短暫視覺提示；仍使用實際已結算的 hit/miss，不另外抽選命中。
6. 網頁主體停用一般文字選取與複製，保留 input、textarea、select 和 contenteditable 正常輸入與複製。此限制不是 DRM，無法防止瀏覽器開發者工具取得文字。
7. 版本沿用 v1.7.3（同 PR #22），以避免不同分支同時改動 package version 的合併衝突；請用網頁右上 Git Commit 短碼區分新舊部署。

## 手動驗收
- 旅店建議長短不同時，其區塊高度與底部按鈕位置是否穩定，狹窄手機與桌面都可完整顯示。
- 任務背包按鈕是否在場景左側清楚可見，能在普通場景／戰鬥場景打開，沒有和 NPC 嘲諷及選項重疊。
- 用兩種以上職業檢查資源圖案；技能卡至少七張時，顯示 3×2 + 下方局部卡片，滑鼠拖曳上下與手機觸控滑動均能操作，選卡未誤觸。
- 黑市初始商品直接顯示，鼠標按住拖曳時不會打開誤選商品，單點商品仍能開啟交易；手機可觸控滑動。
- 閃避成功文字位於中央、字體夠大並避開下方選項；不會吃掉玩家點擊。
- 一般選取及 Ctrl+C 不起作用；輸入/編輯欄位仍能複製、貼上。
- GitHub Actions `npm run build`/`npm test` 通過才合併；實機 UI 仍須人工確認。
