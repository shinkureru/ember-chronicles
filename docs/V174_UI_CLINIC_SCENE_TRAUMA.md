# v1.7.4｜第一批：診所拖曳、SCENE／背包並排、受擊與重傷回饋

> **開發分支** `feature/v1.7.4-ui-clinic-scene-injury`；以 2026-11-12 `main` Commit `58fc3f81214145bf36717b875d7291af8aa2c7a0` 為基準。尚未合併與正式部署，請勿以本文件認定上線。

## 本批變更（不修改任何遊戲數值與存檔結構）
1. **地下診所**：`ClinicDialog` 的實際內容面板採用共用 `useVerticalDragScroll`：桌面左鍵按住上下拖曳、滑鼠滾輪、手機原生觸控與鍵盤焦點滾動；隱藏可見的 scrollbar，但保持可捲動。拖曳會抑制隨後的商品／治療按鈕點擊，避免誤購。按一下按鈕仍正常觸發。
2. **場景劇情與背包**：移除蓋在場景插畫中央的「查看背包」按鈕。新增 `chapter-story-row`，左側固定高度 SCENE 文字區（標題固定、敘事/對話獨立上下拖曳、無捲軸），右側高對比「查看背包」卡片。完整劇情不再被 CSS `line-clamp:2` 靜默截斷。仍可透過畫面上的「全文」讀取完整紀錄。
3. **確實被敵人命中的傷害數字**：`EnemyCounterProjectile` 仍使用引擎 `strike.damage`，僅改 `enemy-counter--hit .enemy-counter__text` 在整體視窗中央大字紅底紅光，接近先前成功閃避的大字效果，保留約 2.75 秒，不再與下方行動卡交疊。未命中仍是原有的灰白「閃避成功」。
4. **嚴重受傷事件**：原 `critical-notice` 是寬高固定 1:1 的單色黑框，大量空白。改成緊湊醫療警示卡：顏色層次、破碎愛心、HP 前後值及心電波形；調整動態與層級、縮短版面無效空白。關閉按鈕保持可點選，嚴重通知顯示 4.6 秒（其他一般提示 2.7 秒），尊重 prefers-reduced-motion。
5. 本批保留既有日誌、人物能力、存檔與戰敗 `MissionTransition` 的持續顯示規則；修理工坊/防具損壞放在**第二批獨立 PR**，不讓新耐久影響本批介面驗收。
6. 原型版本暫沿用現有 `v1.x` 序列，新標示為 **v1.7.4**，頁首的 Git 短碼用來核對 Pages 部署。正式版之前是否轉為 `v0.x.x` 後續另外決策。

## 人工驗收（CI 不可替代實機）
- 開地下診所「診療／每日委託／專賣藥房」，用電腦滑鼠拖曳超出容器的內容、以滾輪移動；點「購買」、「治療」不應因之前拖曳誤觸；手機以手指滑動。不可看到垂直捲軸。
- 任務 1、2 的場景，場景圖不被背包遮住。劇情文字再長也不跑版：SCENE 標題固定，左側內容可拖曳至對話末段；右側「查看背包」開啟舊有任務背包。
- 手機縱向短螢幕（約 360×640）、較大螢幕、桌面；確保選項區仍有足夠空間。
- 敵人命中時顯示大型紅色「遭受攻擊 −X」，X 取自實際已扣血的結算數字；閃避仍顯示原有「閃避成功」。不得有重複彈出或遮住行動選項。
- HP 跨過危急閾值時，重傷卡顯示精準 HP 前後值，圖示、波形與關閉按鈕清楚，長文字不溢出；減少動態效果系統設定下無持續閃爍。
- `npm run build`、`npm test` 及 GitHub Actions 成功；PR 合併後 Pages 應顯示 v1.7.4 + 新 Commit 短碼。
