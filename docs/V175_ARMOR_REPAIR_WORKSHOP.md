# v1.7.5｜修理工坊與四部位防具耐久系統

狀態：開發分支 `feature/v1.7.5-armor-durability-workshop`、以 2026-11-12 的 `main` Commit `6626020d03a8777a44b73aff9cd82da2bf01b4aa` 為基準。**本 PR 待合併與人工驗收，尚未可宣稱已部署。**

## 1. 新防具與裝備欄位
- 防禦判定固定四個部位：頭部 `head`、身體 `body`、手臂 `arms`、腿部 `legs`。
- 維持主手工具 `mainHand`、戰術工具 `utility`、隨身配件 `accessory`；武器、工具絕對不加入損傷或減傷池。
- 舊 `hands` 欄位遷移為 `arms`：已穿戴工作手套不丟失；舊 `wear` 百分比折算為受擊次數。其他角色屬性、舊幣、倉庫、NPC 記憶保留，localStorage 原 KEY 不變。
- 新增 `arm_guard` 護臂固定板、`leg_guard` 護膝防撞墊與精確 SVG 圖案；可從有限次環境搜查獲得，或在黑市修理師貨架購買。人物檔案及任務背包能查看新裝備欄位。

## 2. 何時損壞
- 只有 `ENEMY_COUNTER_HIT` 的 `hit === true`、玩家確實損失生命（`lost > 0`）才發生一次防具部位抽選。閃避、無造成傷害、反覆呼叫相同攻擊事件都不能磨損。
- 隨機命中權重：身體 40%，頭部 20%，手臂 20%，腿部 20%；**只在當下已裝備且真正具有防禦效果的部位中重新正規化**。因此若只穿背心，背心每次真正受擊均會磨損，沒有「命中不存在的防具」。
- 單次攻擊最多影響一件防具；同一物品 `town.armorHits[itemId]` 上限 10。耐久 `town.wear[itemId]` 每次下降 7%，最低 30%，防具不消失。
- 受擊 0～2 次正常、3～4 次輕微（85% 防禦）、5～9 次中度（65%）、10 次嚴重（35%）。損壞狀態和升級效果在 `getEquippedDefense` 同一公式計算；UI 不另算一套假防禦。
- 受擊與傷害回饋使用同一 reducer 的實際 HP 變化。生命只剩 1 時，被打出原始 7 傷害，畫面顯示真實 `−1`。

## 3. 防禦平衡
- 防禦不加關卡成功率／交涉率／潛行率、不會放大任一敵人的失敗反思加成，也不直接提高 HP 上限。
- `finalDamage = max(1, rawDamage − min(floor(rawDamage × 0.35), floor(totalDefense / 4)))`（rawDamage>0）。
- 玩家原始受傷 7 點時，即使堆滿防具，最多減傷 2 點，仍受 5 點；原始 10 點最多減 3 點，仍受 7 點。
- 護臂/護膝各 3 基礎防禦，工作帽 2、防護背心 10。精工改良每階 +2 基礎防禦但仍受減傷比例上限限制，避免堆疊形成免傷。
- 受擊數跨任務保存，帶來持續性的維修壓力。所有有效傷害均增加傷口狀態的原規則不變。

## 4. 修理工坊
- 點擊城鎮「修理工坊」主設施卡立即開啟獨立視窗；提供工坊場景、四部位卡片、選取裝備、耐久進度、受擊數、目前/恢復後全身防禦、實際花費、精工改良、未營業/金錢/材料不足等阻擋文字。
- 修理費依傷害階段與部位：頭部 3/5/10 次為 8/18/34 舊幣；身體為 10/22/40；手臂和腿部各為 7/16/30。4 次、6～9 次等階段內受傷更深會額外加價，1～2 次微損有低價修復。
- 不允許完好防具重複支付修理費或洗出 Buff；不接受武器/非防護衣物作為防具修理。
- `applyTownService` 與 UI 均調用 `getTownServiceFee`／`armorRepairFee`，避免預覽與實際扣幣不同。修完耐久 100%、受擊歸零，裝備仍保留。
- 每次從損壞狀態完全修復有 **25%** 機率得到「完美修理」，該物品下次任務額外 **+1 防禦**；只限下一次任務，無法無限疊加，其他部位不受影響。使用存檔中的 `rngSeed` 保持可測試的固定隨機行為。
- 舊的精工改良仍保留：45 舊幣＋工業膠帶或電線 1 份，單件最多 III 階；工坊視窗與原有城鎮面板均可操作。

## 5. 測試與驗收

實機建議：
1. 先確認 `v1.7.5` 與新 Commit；進城鎮點「修理工坊」大卡是否直接開啟。四部位未裝備時顯示指引。
2. 裝備工作帽／背心／護臂／護膝，用人物檔案與戰鬥背包確認同樣的槽位。受擊多次後各件進度獨立增長，其他裝備不受損。
3. 須真正被命中才受損；閃避後不受損。同一回合只會有一個防具減耐久，等候反擊時不能重複觸發。
4. 修理費在不同損壞階段與部位確實不同；按下修復後扣同樣舊幣、耐久回滿。體驗一般修復與完美修復差異。
5. 在有完美修理的下次任務確有 +1 單部位防禦，回城後失效。高防禦仍不能完全免疫 6/7/10 點攻擊。
6. 用 v1.7.4 之前的舊存檔開啟，檢查手套移至手臂、背包與 NPC 記憶、錢幣不消失。
7. 先確認 TypeScript、Vitest、PR CI；合併後 Pages success 並驗收。**自動化測試 ≠ 已完成真機驗收**。
