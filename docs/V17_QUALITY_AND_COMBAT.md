# v1.7.0｜版本顯示、旅店預覽、手動退出戰敗與敵人嘲諷

**分支：** `feature/v1.7-build-combat-inn-qa`。此文件僅記錄實作與待驗收，合併前不代表已部署。

1. 頁首常態顯示 `v1.7.0 · <短 SHA>`；版號由 `package.json` 產生，GitHub Pages 建置時的 `GITHUB_SHA` 短碼由 Vite 編譯注入。顯示的是**瀏覽器實際下載的前端 bundle**，可用來區別 Actions 成功但使用者尚未取得新網頁。手機小螢幕至少顯示版號，完整 SHA 可於頁首提示查看。
2. 旅店不能開啟預覽的原因：頁面 `viewport-page` 設置 `overflow:hidden`，但模態視窗原本畫在此容器內。改用 React Portal 將 `InnRestDialog` 放至 `document.body`，可用 ESC / 點背景關閉。即使血量、體力全滿仍可點開並使用；若金錢不足或當天次數已達上限，在視窗顯示原因並禁用確認，不讓畫面像無反應。
3. 戰敗結果只由玩家點擊「結束戰敗 · 返回地圖」離開；勝利、撤退及其他轉場仍採原計時。
4. 敵人反擊的 waiting 從 2 秒變 0.5 秒；其餘出手動畫、傷害數字可讀時間與致命傷退場保留原設定。
5. 敵人樣貌出現的 `confrontation` 場景，在玩家提交**第一張攻擊牌前**，約進入 2.5 秒開始顯示嘲諷，之後每隔 10 秒嘲諷一次；每次一個 3.2 秒的短氣泡，共 20 句，5–15 字左右。第一張攻擊牌成功或失敗都標記 `attacked_enemy` 並停止嘲諷；新任務開始會清除標記。
6. 新增 `tests/v17-qa-and-taunts.test.ts`，調整 `tests/v13-systems.test.ts`。

## 必須人工驗收
- Merge 並完成 Pages 部署後，正式網站的頁首版號與 SHA 應與實際部署來源相符；若顯示舊碼，可重新載入而不要僅看 Actions 綠燈。
- 旅店的滿血、滿體力、金錢不足、兩次/天使用上限，以及手機視窗滑動與關閉。
- 戰敗畫面放置一分鐘仍不消失，點右下角才返回地圖。
- 敵人嘲諷不蓋住卡片、同一時間不超過一個；攻擊後停止，切換關卡再恢復；敵人反擊約 0.5 秒開始。
